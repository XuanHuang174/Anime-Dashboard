# N1：受控内容范围、访问资格与审计合同

日期：2026-10-21。用户确认：建立服务端受控资格合同，默认全部不开放；不自动授予任何账号资格。

## 1. 本阶段交付与不做事项

- 交付：独立版本化合同、只读序列化结构、默认拒绝的合同解析器、公共目录只读审计命令、冻结 JSON、隔离测试和 N2/N3 安全矩阵。
- 不做：不开放 NSFW 参数或 UI，不改变 V1 排序及安全目录，不建立资格业务表，不签发资格，不改私人评分/标签/长评，不下载封面，不启用 V2。
- 合同解析器是 **N1 准备代码，尚未接入线上服务**，不是已经完成的成年认证服务。设置变量或管理员身份不能让它放行。
- 线上现有请求继续按原合同：未定义 `content_scope` / `nsfw` / `include_nsfw` 参数返回 400；成人和未知分级详情/加入仍 404。

## 2. 冻结合同

文件：`evaluation/content-scope.n1.v1.json`。

| 字段 | N1 固定值 / 语义 |
| --- | --- |
| `contract_version` | `recommendations.content-scope.n1.v1` |
| `policy_version` | `content-scope.closed.v1` |
| `adult_access_enabled` | `false` |
| `serving_integration` | `false` |
| `eligibility_provider` / `eligibility_version` | `unconfigured` / `0` |
| 可选范围 | 仅 `safe` |
| 未来范围名 | `include_adult`，仅表达将来的协议值，不代表当前允许 |
| 未知分级 | 始终排除 |
| 成人封面 | 仅中性占位，不回退外部原图 |
| 自动画像来源 | 继续仅非成人安全作品 |
| 公共展示 | 与私人推荐范围完全独立 |

`resolve_n1_scope(request.user, requested_scope)` 仅接受服务端认证用户对象，禁止从请求读取其他用户 ID。

- 未登录/未保存的用户：`NotAuthenticated`。
- 未定义的范围：`ValidationError`。
- 请求 `safe`：`allowed=true, effective_scope=safe`。
- 请求 `include_adult`：`allowed=false, effective_scope=safe, reason_code=adult_eligibility_unavailable`。
- 任何账号（包括管理员、超级用户、两个测试账号）结果相同；客户端年龄、确认复选框、个人偏好都不是授权依据。
- 拒绝结果不能静默当作成人请求成功。N2 接入时必须先拒绝，再决定是否查询作品，避免暴露作品存在性。
- `require_n1_scope()` 是预留的拒绝执行入口，对不允许范围明确抛出 403；仍未接入线上路由。
- `subject_binding` 和 `scope_revision` 使用服务端 HMAC-SHA256，绑定用户、请求范围、策略、有效范围及资格版本；不输出原始用户 ID。对象冻结，避免请求间共享可变状态。
- 这两个绑定值是上下文指纹，不是资格授权令牌；前端回传 `allowed=true` 或指纹都不能证明资格。N2 必须重新查询权威状态，并设计有有效期的签名上下文。
- 此版本的资格版本固定为 0，因为尚无资格签发/吊销。N2 必须增加权威资格来源及单调更新版本，不能把固定 0 当作正式权限版本。

## 3. 资格与内容双重放行边界

“服务端受控”不等于相信前端勾选，也不等于管理员默认成年。后续必须明确资格签发、撤销、过期及审计依据，资格不可由客户端布尔值直接设置。

本阶段不额外收集身份证、生日或其他身份材料，不声称实现年龄验证。实际适用人群、年龄保障方案及平台/地区要求仍是 N2 开放前的人工确认节点。

作品的 NSFW 标记只是目录来源分类，不是合法性、年龄合适性或内容审核凭据。禁止内容不能仅凭 `nsfw=True` 获准展示；尤其不能据此放行涉及未成年人的性内容。后续需要独立内容放行审核，不根据标题模糊猜测。

即使用户资格满足，也还要满足：功能总开关已批准启用、作品已明确分级且通过内容放行、请求主动选择范围。任一条件未知均拒绝。

## 5. N2 预留的全链路行为

以下是下一阶段合同，不是当前已开放的接口。

| 路径 | 必须满足的边界 |
| --- | --- |
| 推荐列表/候选 | 在 400 候选截取前统一内容范围，V1 排序公式不变；成人标记不当作题材或喜好 |
| 高分画像/明确偏好 | 画像继续仅安全样本；不因浏览成人范围改写用户偏好 |
| 详情/证据 | 校验同用户、范围、资格/策略版本；不展示越权旧证据 |
| 加入想看 | 同一内容范围；幂等、不覆盖评分/长评；不得顺带公开到公共库 |
| 反馈/撤销/已隐藏 | 用户隔离；撤销不等于允许越过分级和资格要求 |
| 封面 | 默认中性占位；不能通过原图字段/外链绕过范围 |
| 推荐详情资源区 | 复用既有组件/安全代理；范围变化立即取消并清理旧资源会话，不宣称改变独立手动检索的所有内容政策 |
| 公共搜索/公开手账 | 不继承私人推荐资格，不因本功能自动公开；须另行验证，不把本次审计当作全站内容审核 |

预定失败语义：未知参数 400；未登录按既有认证规则拒绝；显式成人范围但无资格 403；范围内不可见/未知作品 404；范围、资格、目录安全或策略变化使旧快照/证据失效 409。正式接入需保留错误码及恢复入口，不能返回成功后悄悄放宽或混入旧结果。

缓存/游标/证据令牌需共同绑定：用户、`content_scope`、资格版本、策略/放行版本、总开关代次、目录安全版本及既有画像/偏好/反馈/手账版本。关闭范围或吊销资格时中止旧请求、清空旧详情/资源，不能用 TTL 等待过期代替即时隔离。

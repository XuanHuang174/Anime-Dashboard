# 片单视觉、移动端入口与筛选优化

在 E3 基础上统一片单展示和操作，不改变私人片单、观看历程、观看计划及本机导出的保存边界。“导入差异预览与同步增强”仍留待后续讨论。

## 展示与确认操作

- 片单标题的锁使用与观看计划、回顾相同的单色图标。新建、编辑、选片、重新关联、排序和推荐收录确认操作统一靠右，实际 DOM 顺序为确认／保存在前、取消在最右；黄色底栏中主按钮使用青绿，取消白色、危险操作红色，禁用按钮保留可读文字。选片底栏持续显示已选数量；抽屉内容独立滚动，底栏固定。
- 首页封面使用 3:4 画框及 `object-fit:contain` 完整展示，不裁切主体；卡片最大宽度约 300px，不因只有一张片单而拉伸。缺图／坏图继续占位。新增“重置片单筛选”，恢复名称为空、当前片单、全部置顶和第一页；刷新保留已应用条件。
- 详情名称、数量、简介与工具区集中排列。桌面条目海报 100×140px、手机 64×90px；操作区两列，减少竖排按钮撑高整行。资料显示中日文名、季度、状态进度、个人评分及前三个标签。空理由轻量提示；长简介／理由可展开全文，保存和图片导出保留完整文字。
- 普通“片单已保存”反馈约 4.5 秒收起，冲突、错误和原操作核对提示不自动消失。作品详情／安排返回尽量恢复原筛选、页码、滚动及触发按钮焦点。分页文案统一“上一页／下一页”。

## 选片与手机入口

选片抽屉复用手账的搜索选择器，年份、题材和快捷筛选均可键入搜索；选项面板最多约 280px，根据抽屉可用空间向上或向下展开。支持方向键、Enter、Esc 与焦点返回；第一次 Esc 仅关闭下拉框，避免连带关闭收录面板。主手账已有选择器沿用原布局。

候选行补齐日文名、状态、已看／总集数及季度，统一左对齐；没有日文名则省略该行，不留空白。海报缺失使用等尺寸占位。已收录项明确说明不可重复勾选。筛选与分页保留已选作品，“清空筛选”和“清空已选”分别处理条件与勾选，不互相清空。

手机列表的日文名下方增加资源／收录操作组，不依赖被隐藏的桌面操作列；收录按钮保留图标和短文字，窄屏不拆成竖排，也不触发整行编辑。预览模式与他人手账不出现私人收录写入入口。

“收录本页作品到片单”整合在分页数量卡片内，沿用该栏边框与间距；右侧排序提示职责不变。已分页时只提供当前页候选，全部显示且结果不超过 100 部时也可收录当前结果。超过 100 部明确提示先选择分页数量，不静默截断；加载、搜索条件尚在更新、页码尚未加载完成时禁用，避免收录旧结果。所有批量入口仍需打开后明确勾选。

## 片单内筛选接口

`GET /api/curations/<UUID>/` 新增可选参数：

| 参数 | 取值与含义 |
| --- | --- |
| `search` | 最多 100 字符，中／日文名称不区分大小写匹配；失效条目按名称快照搜索 |
| `status` | `all`、`plan`、`watching`、`completed`、`on_hold` |
| `tag` | `all` 或本人作品的准确题材／自定义标签 |
| `year` | `all` 或 1000–9999 四位年份，按当前私人放送资料筛选 |
| `availability` | `all`、`available`、`unavailable` |

在完整片单上组合筛选后再分页，继续使用原版本与所有权校验；不局限当前 12 项。响应 `count` 为匹配数、`total_count` 为片单总数，`collection.entry_count` 仍为完整总数。`filter_options` 提供整张片单的年份和标签，`record.tags` 来自当前私人基础标签及自定义标签，不改公开序列化。

结果保持原编排顺序，序号使用原 `position + 1`；不因筛选重新编号。失效条目不推定观看状态、题材或年份。无结果时提供清空条件，真正空片单则提供收录入口。名称与状态默认展示，标签、年份和失效条件收在“更多筛选”。应用条件回到第一页；刷新、详情往返保留已应用条件。

排序始终读取完整片单，包括其他分页和失效条目；界面明确提示临时忽略浏览筛选，退出／保存后恢复原条件和页码。完整读取校验拒绝把筛选子集误当成整张片单。导出按钮明确为“导出完整片单长图”，不受浏览条件影响，继续使用原来的私人选项默认值和签名复核。

- 前端 549 项测试及生产构建通过；新增过滤结果／完整总数区分、拒绝对子集排序、筛选跨页保留和返回首页清理参数的契约测试。
- 隔离 PostgreSQL 135 项测试通过，覆盖原片单、历程、计划、回顾、导出及新增四项筛选测试；验证 105 项跨页搜索、私人日文名／季度／基础与自定义标签、失效快照、非法参数与本人边界、筛选不写入及导出仍完整。只读导出测试从真实事务边界启动。Django 系统与迁移漂移检查通过，无新增迁移。

- 原 E2 浏览器全流程通过，包括完整排序、跨页封面、置顶归档、回执丢失原 UUID 重试、冲突保留草稿、失效关联、公开隔离。E3 实际 106 项／14 页 ZIP、单 PNG、122 部年度候选、推荐两步保存及取消保留记录回归通过；普通动画下月度／自选来源、实际安排保存与草稿边界通过。

浏览器只使用 `config.journal_polish_e2e_settings` 和忽略的 `.tools/watch-history-a3.sqlite3`。执行 `scripts/seed-curation-polish-e2e.py` 创建独立合成账号，在本机启动 8000／5191，设置本机 `PLAYWRIGHT_MODULE` 后于 frontend 执行 `node scripts/test-curation-polish.mjs`；`CURATION_TEST_MOTION=no-preference` 可复跑普通动画。凭据、数据库、日志和截图不提交；SVG 为专门的本地合成海报夹具。E2／E3 回归使用各自独立新种子。

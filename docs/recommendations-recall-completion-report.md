# V2 有界召回实验与止损结论（2026-10-19）

## 结论

**本轮没有证明推荐质量改善。按照用户事先约定，停止当前 V2 路线的上线推进，继续使用线上 V1，不再追加调参轮次。**

仅保留离线代码、测试和历史产物供审计；没有打开 V2、没有改变 V1 排序或前端行为。
这不是“证明所有可能的 V2 都无效”，而是当前路线缺乏足够稳定收益，不值得继续以用户验收为代价反复试验。
以后若重新研究，需要另立方案和独立评测，不把这 52 个已揭示目标包装成新盲测。

## 同条件与规则

原 13 个账号、52 个目标、四目标整组留出。与前次 20261018 冻结文件逐项核对，账号输入、目标及顺序、目录版本均完全相同。
明确偏好保持原样，训练集同时移除四个目标的样本和已有记录别名。
当前数据只是已消耗的开发诊断集，不代表独立用户或总体推荐质量。

三对照组：V1、保护型 V2、本轮 `append-only-recall.v1`。
本轮只保留原候选并填补空闲名额；分数、证据、重排不变，最多 400 个候选、120 个结果。
每组、每类、每个账号运行两次，共 234 次排名；重复顺序、内部基础分和证据摘要一致。
其他类别与冷启动路径未作质量优化；前者有自然对照完全一致检查，后者为隔离合成测试，不声称完成新的自然冷启动评测。

## 瓶颈定位与重要计数纠正

1. **多数池已经满，不能靠空位补全解决。** 12/13 个账号的原发现候选池已是 400。
   仅样本 13 从 243 补到 400；增加的 157 条真实关联作品均经当前安全/证据复核，但没有新增目标入池或前排命中。
2. **召回截断确实存在。** 52 个合格发现目标中，39 个未入池；37 个基础分低于相对召回保留门槛。
   这两个数量有重叠，不能相加，也不把“低于门槛”当作用户不喜欢。
3. **排序也存在独立问题。** 已入池的 13 个目标中，5 个未进前 120；另 5 个进了前 120、未进前 10。
   V1 原命中目标在 V2 基础分排名 1696，实际已经入池，但未进前 120；其聚合题材关联排名为 64。
   所以只扩召回并不足以找回这个目标。
4. **阶段位置不是池容量或最终排名。** 上述目标的原 `pool.positions=363` 是它在 400 个候选中的位置，
   `validated.positions=177` 是水合列表中的位置，不能误读成“池只有 363 条/复核后只有 177 条”。
   本报告同时核对各阶段的 `count` 与 `positions`，不用错误的容量推断支持收益结论。

基于以上证据，当前主要瓶颈不是单纯的 Neon 跨网延迟，而是来源题材组合得分、召回门槛与真实留出目标之间缺乏稳定一致性。
此前聚合替换和双视图融合又丢失原 V2 命中；这些已知开发结果没有证明简单融合能兼得两者优势。
本次仅排除了“保守填空位”这条修复路径，**没有宣称修好了满池召回与前排相关性**。

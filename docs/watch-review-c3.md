# C3：回顾长图导出、内容选择与完整验收

C3 接在 [C1 统计基础](watch-review-c1.md) 和 [C2 私人工作区](watch-review-c2.md) 后交付。月度／自选时间段回顾已完成，年度展示仍待后续开发。

## 导出入口与内容

本人回顾页提供“导出回顾长图”。捕获的是已应用的日期区间，不使用尚未提交的时间草稿；不继承当前列表分区或分页大小。打开原生模态面板后，选择内容并“读取并预览完整内容”，确认后才下载。

可选统计摘要、完整作品清单、完成轮次、随记与补录／轮次备注，以及海报。默认只选择摘要和作品清单，私人文字与海报默认关闭。未勾选私人文字时，即使选择完成轮次也不输出轮次备注。用户主动选择文字后明确说明文件包含私人内容。

各分区完整读取全部分页，不把当前页当作完整报告。每个分区保持自身去重口径，分区间可能包含同一作品。摘要始终是完整区间统计，不随导出内容裁减。日期不够精确或未知的记录不加入确定清单，图片底部保留覆盖说明；未知日期数量来自本人全部历程。评分使用有效轮次评分，作品名称和海报标明当前手账资料。

## 图像和下载

使用已有 html2canvas 生成 1350px 宽 PNG，不新增依赖。预览可逐张核对，手机可在预览容器内横向查看固定宽度报告，不撑开整个面板。长文字完整保留并以“续”标注；按实测布局拆页，不裁切文字或静默缩短内容。

单页下载 PNG，多页用 ZIP STORE 打包成一次下载，避免浏览器自动多文件下载限制。ZIP 文件名使用 UTF-8，包含逐张 CRC32 与完整目录；不含操作凭据、原始事件快照、用户标识、报告源 JSON 或额外私人文本副本。文件名区分回顾时间与页码，图片标注总页数及上海时区的读取依据时间。

导出最多 500 条所选分区条目、100 张图片，每个画板高不超过 5000 CSS 像素；超限明确拒绝，要求缩短区间或减少分区，不返回部分成功。图像逐张渲染后释放画布。需要海报时复用已有图片代理，最多并发两次、24 个不同来源，单张数据上限约 1.5MB；失败或超限使用可见占位并告知数量，所有作品文字继续完整保留。原海报地址与手账数据不改写。

## 资料一致性与隐私

完整分页、预览完成后、生成前及下载前均沿用原 C1 签名凭据验证。任一分页、日期、摘要或内容不完整，跨页重复，资料更正、撤销、清空、恢复或凭据过期导致冲突时，停止并要求关闭、刷新回顾后重新预览。不自动换成未被用户核对的新报告下载。

生成过程可取消或关闭，之后不发起下载；卸载和账号变化会中止请求并丢弃迟到结果。打开导出面板时暂停回顾的窗口聚焦刷新，避免操作预览时改变底层报告。导出只读，不修改状态、评分、历程或计划；不提交到共创／精选，不新增公开接口、永久报告记录、定时任务或本地存储。只发起浏览器本机下载，是否后续分享由用户自行决定。

## 验收

- 523 项前端测试通过：含完整分页、同凭据读取、重复／资料变化／超限拒绝、取消、私人文字选择、长文字连续性及 ZIP CRC／目录。
- 隔离本地 PostgreSQL 中 97 项回顾、历程、清空恢复与计划关联回归通过；Django 检查、迁移漂移检查通过。
- C2 完整浏览器回归通过，包括日期草稿、409 重读、焦点刷新、编辑边界和公开隐私。
- C3 真实浏览器下载了单张 PNG 和三张 PNG 的 ZIP；校验压缩包 CRC 和图片尺寸并视觉检查。验证完整清单跨当前页、私人文字默认关闭、完整长感想、封面失败占位、320／390／1440px 面板、真实资料更正阻止下载、取消阻止下载、无页面写请求及运行错误。
- 生产构建通过，保留已有大分包提示；无需新增迁移、依赖或环境变量，后端须已部署 C1。

本地复跑沿用 C2 的隔离服务配置：先运行 `scripts/seed-watch-review-c2-e2e.py` 创建新合成账号，启动 8000 后端和 5191 前端，再在 frontend 执行 `node scripts/test-watch-review-c3.mjs`，设置本机 `PLAYWRIGHT_MODULE`。脚本只更正合成账号资料、故意模拟一次封面失败；PNG、ZIP、令牌和日志均在忽略的 `.tools` 内。每次完整重跑前重新生成账号。未操作生产数据。

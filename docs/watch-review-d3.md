# D3：年度回顾长图导出与完整验收

接续 [D1 年度口径与接口](watch-review-d1.md)、[D2 年度页面与月份往返](watch-review-d2.md)，完成年度回顾的本机图片导出，复用 [C3](watch-review-c3.md) 的内容选择、私人文字保护与 PNG／ZIP 下载流程。没有新增后端接口、迁移、依赖或环境变量。

## 导出内容

“按年度”应用年份后可直接选择“导出回顾长图”。默认选择统计摘要、十二个月分布／月份待补充说明、完整作品清单；完成轮次、随记与补录／轮次备注、海报默认关闭。月份分布可单独取消，私人文字仍须主动勾选，即使选择完成轮次也不会默认输出轮次备注。

图片包含自然年标题、起止日期、读取依据时间和页码。读取时属于当前上海年份的报告标注“年度进行中”。月份分布输出固定的每月完成轮次柱状图和十二行明细，明细包含开始／完成作品与轮次、重看完成轮次、随记与补录数。数字直接使用本次年度响应，不从平均值反算，不把逐月作品数相加冒充全年去重作品数。

零值仅表示没有可归属的已记录资料。“属于本年，月份待补充”独立说明事实数、涉及作品数和分类数量，这些资料已计入年度总览，但不会补造月份。每页底部仍保留这层说明，即使未选择分布。完全未知日期继续标明来自本人全部历程，不称为本年度遗漏。实际日期原有年／月精度完整保留。

## 完整读取和资料一致性

导出使用当前已应用的年份及原签名凭据，始终发送 `year` 参数，不转换为自选日期。尚未应用的年份草稿、正在浏览的分区／页码和页面分页大小不改变导出范围。对所选作品、完成轮次和随记分区逐一读取全部分页；摘要与月份表来自全年依据，不随选择缩减统计。

预览及下载的每次校验均比较同一凭据、期间、全年摘要、覆盖说明和完整 `annual` 对象。即使全年合计相同，只是资料更正导致月份归属变化，也拒绝下载旧报告。分页缺失、重复、结构不完整、源资料变化或凭据过期均明确报错，不拼接新旧版本，不返回截断成功。

完整内容读取后先在独立画板测量并拆页，尺寸和最终校验通过后才显示可下载预览。下载不会悄悄重新分页；若布局超限，要求重新读取。预览默认适应宽度，可切换原尺寸，缩放不改变导出清晰度。单张输出 1350px 宽 PNG，多张打包一个 UTF-8 文件名 ZIP；年度文件名为 `YYYY年观看回顾`，各图片带顺序编号。

## 边界和隐私

保留最多 500 条所选分区条目、100 页、每页 5000 CSS 像素的边界；超限拒绝完整导出，不删除部分内容来满足限制。长私人文字按 Unicode 字符拆为连续段落。海报最多代理读取 24 个不同来源、并发两次、每张数据约 1.5MB；请求失败、损坏图片或超过数量均使用可见占位并提示数量。所有作品文字继续完整保留。

读取和生成中可取消或关闭，取消后不启动下载。账号变化、组件卸载和迟到响应继续受保护；逐张生成后释放画布。只读私人来源，只向本机下载，不生成公开链接、永久年度报告或后台任务，不向共创／精选投稿；输出不包含用户标识、签名凭据或原始接口 JSON。

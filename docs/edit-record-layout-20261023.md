# 预览贴顶与作品编辑布局调整（2026-10-23）

## 预览与编辑页头

将页头间隔按当前模式区分：编辑模式保留 16px 内部顶部间隔，预览模式的红色背景直接贴页面上边缘。页面仍建立独立块格式化上下文，防止编辑页头外边距把背景推出页面。共享手账的预览页同样贴顶。

## 编辑面板

- 移除桌面弹窗固定的 `96vh` 高度。整体按内容确定高度，仅以视口减去安全间隔作为上限；空间不足时允许主体滚动，原有页头及删除、保存、关闭操作栏留在主体外。
- 海报保持原有 3:4 比例，不再随窗口高度纵向撑长。标签列表按内容排列行，不再把少数标签拉伸成大块。
- 桌面编辑工作区在 18–26rem 之间随视口高度调整，标签和预设两列沿用既有布局与宽度。两侧列表分别滚动；“自定义新标签”输入与“标签管理／剧情简介／个人评价”切换栏作为非收缩兄弟区域，不参与列表滚动。
- 保留原有 1024px 桌面断点、手机和平板堆叠布局，以及原有配色、边框、阴影、字体和按钮样式。
- 不修改上传、表单校验、私人记录更新、删除确认、保存及关闭处理函数；未调整数据库或接口。

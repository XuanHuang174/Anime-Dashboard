# 扩展 11E：按标签找前端

日期：2026-10-24。11A–11E 已实施，11F 后续发布工程已交付，见 [11F 发布记录](recommendations-11f.md)；线上配置及认证验收待部署操作。本阶段没有开启生产探索开关。

## 页面与入口

沿用已确认导航：个性化推荐、单番相似、按标签找。后台能力启用且声明支持标签合同后，第三个入口才可进入；未启用时仍显示“尚未开放”。没有新增环境变量、数据库迁移或独立生产放行路径。

`/recommendations/tags` 初始显示选择题材引导，右侧为“探索条件”。选择器桌面使用现有右侧面板，手机使用同一个底部面板；可滚动编辑区与固定执行按钮复用现有筛选结构。结果沿用本批首推、条件便笺、还有更多、分页换批、Memphis 返回顶部与首次文档入场动画。手机三入口等宽排列，标签条件操作上下排列。

包含 1–5 个题材、排除 0–5 个，互斥且不重复。选择器支持名称搜索、名称/数量排序、ALL/ANY 和题材关联/Bangumi 评分排序。51 个标准题材全部显示，包括零数量；数量明确表示**已应用内容范围的整个目录**，不叠加类型、年份、评分、已有记录或隐藏条件。NSFW 开关的未应用草稿不会伪装成新的数量范围。

## 草稿、执行与恢复

- 选择标签、切换规则/排序、编辑普通条件、移除条件芯片均先进入草稿，点击“开始探索”才执行。关闭面板及切换探索模式保留草稿。
- 已生效摘要只来自通过合同校验的成功响应。读取中或失败时不展示新草稿为已生效条件；失败仍保留草稿及重试入口。
- 空结果不会自动移除排除题材或从 ALL 改为 ANY。明确按钮可重新执行 ANY；清除排除只编辑草稿，仍需手动执行。
- 本页不读取个人高分画像，不调用偏好保存接口，不写入长期偏好。
- 使用现有 owner/session 内存缓存，保留各模式查询、批次、结果与滚动位置；刷新/账号切换不复用缓存。切换模式会取消旧查询、目录和详情请求，关闭旧资源会话。
- 有效 NSFW 本次浏览选择由三种模式共用，不进入 URL 或持久偏好。真实范围失效按现有逻辑恢复普通范围；探索快照变化只提示重新探索。

## 标准题材与公开链接

推荐卡片、推荐详情及私人手账详情增加“探索这个题材”按钮。按钮只根据服务端版本化合同的**精确标准名称**生成，自定义私人标签保持原显示；不根据私人评分、长评或标签文本推测标准题材。编辑手账存在未保存修改时不显示跳转，避免丢失编辑内容。公开手账不新增私人探索入口。

链接示例：`/recommendations/tags?include=日常,音乐&exclude=战斗&match=any&sort=score`。

链接只包含标准题材与普通筛选。解析拒绝重复/未知参数、非标准题材、包含排除冲突、空标签及非法筛选；不会序列化账户、个人评分、长评、NSFW 授权、快照、证据或游标。接收者以自身内容范围、已有记录及隐藏反馈重新执行。原始 URL 可以复制分享；没有另加外部分享服务。

## 合同与操作闭环

标签查询保持与相似查询互斥，独立验证 `tag-explore.v1` / `selected_tags` / `source: null`。校验实际命中集合、ALL 与排除硬约束、普通筛选、范围、版本及快照；续页比较标签数组内容，不以数组引用或重新签名后的字节作为同一性。

HTTP 初次查询把包含/排除数组转为逗号字段，空排除省略；续页只传签名游标。列表和详情展示实际命中题材与命中数量，不展示个人评分或喜欢概率。排除说明明确不能保证作品绝无相关内容。

单番和标签共用 `useExplorationInteractions` 与 `ExplorationDialogs`：详情、资源、想看、隐藏、撤销及身份处理使用同一实现。确认加入想看后立即作废整份旧详情及资源，再读取完整新详情；旧列表保留位置并提示重新探索，不覆盖已有手账内容。请求取消与账号写入门禁沿用现有状态机。

## 验证

- 前端 341 项测试通过，覆盖公开条件 URL、标准题材入口、草稿呈现、数组与 HTTP 边界、标签硬约束/证据、范围、续页恢复、晚到响应取消及想看后完整详情刷新。
- 隔离本地 PostgreSQL：探索相关 95 项、既有推荐/范围/身份/浏览闭环 120 项，共 215 项通过。真实 Django 标签 ALL/ANY、两种排序、分页、详情、空结果及永久审核范围响应均通过实际 JavaScript 适配器。
- 本地合成目录浏览器验收 1440px / 390px：包含/排除、规则和排序、草稿保留、跨模式第 2 批恢复、追加分页、详情、想看后刷新、资源面板、隐藏及管理页撤销、空结果主动改为 ANY、NSFW 选择保持。资源检索由隔离适配器拦截，仅验证面板及失败回退，不查询真实外部资源。

- 所有验收均使用合成作品和本地隔离账号；未改生产开关或线上账号数据。11F 再执行部署环境验收与正式开放。

这是一批克制扩充，不是对剩余无题材目录的全面补齐。大量缺失来自形式、来源、制作信息等非题材标签；不能为了提高覆盖率而强行转成题材。以当前版本定义判断的安全元数据冲突也应另行复核，不应靠扩充标签掩盖。

## 样例与限制

每个标签至多两部安全公共作品样例见 JSON，按 Bangumi ID 固定顺序展示，供人工核对，不用来猜测标签含义；不是随机质量评测。
安全标记目录有 588 部带需复核的内容提示标签；这些作品的样例名称已抑制。只作元数据核对线索，不自动改分级；安全统计仍依据当前后端显式分级。
“神作”等被现行清洗器提前排除的标签不在未知题材库存中，表中 0 表示本次库存未计数，不代表原始目录完全没有该词。
本轮不修改原始目录、用户标签、个人评分或长评，不新增前端选项，不改变 V1 排序，不启用 V2。

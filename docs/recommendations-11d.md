# 扩展 11D：标签探索后端

日期：2026-10-24。状态：后端已实现，本地隔离验收通过。标签页的选择器、条件摘要和结果界面留在 11E；本次未修改生产探索开关或线上数据。

## 已实现的接口

### 标准题材与数量

```text
GET /api/recommendations/explore/options/
GET /api/recommendations/explore/options/?content_scope=include_adult
```

返回 `recommendations.explore.options.v1`、51 个标准题材及其数量、`catalog_count`、词表 / 特征规则 / 目录版本和当前内容范围。零数量题材仍返回，顺序沿用标准词表，供 11E 在前端搜索或按名称 / 数量浏览。

数量定义固定为 `scoped_catalog_without_result_filters`：当前内容范围的目录数量，未叠加年份、类型、评分、已有手账或隐藏反馈。每部作品对同一标准题材最多计数一次；批准别名和重复原标签先归一化，管理标签、国家、年份等不计入题材。`catalog_count` 包含范围内尚无有效题材的作品，因此不能把各题材数量相加当作目录总量。

接口只接受内容范围参数；附带类型、标签、评分、关键词或用户 ID 会返回 400，避免把面板数量误当作当前查询剩余数量。数量与结果使用同一个公共特征规则和当前审核范围，不读取私人手账、评分或偏好。

### 查询与固定分页

```text
GET /api/recommendations/explore/?intent=tags&include_tags=音乐,日常&exclude_tags=战斗&match=all&sort=relevance
GET /api/recommendations/explore/?intent=tags&include_tags=音乐,日常&match=any&sort=score
GET /api/recommendations/explore/?cursor=<next_page_cursor 或 next_batch_cursor>
```

- 包含 1–5 个题材，排除 0–5 个；使用现行标准词表和批准别名，归一化后排序、去重。同一题材同时包含和排除返回 400；未知题材、只有排除、重复参数、混入 seed 或私人字段均拒绝。
- GET 的标签组使用逗号分隔；无排除时省略 `exclude_tags`。响应及签名快照中的查询使用规范化数组，续页在服务端严格还原并验证，不把数组格式放宽成公共 HTTP 输入。
- ALL 要求包含集合全部命中；ANY 要求至少命中一个；两种模式都硬排除任何命中的排除题材。
- 类型、年份、公共评分、已有记录与隐藏反馈均在排序和截取之前应用，遍历完整范围目录，不复用个人推荐的 400 条召回截断。没有结果返回真实零结果，不自动放宽条件。
- `eligible_count` 是本次完整条件的合格数量；`returned_count` 是实际收录到有序快照的数量，最多 120；每批 24、每页 12，快照 15 分钟。目录超过 50,000 条明确不可用，不返回截断的“全库数量”。

排除只针对目录已有的题材标注，不保证作品绝无相关内容；选项响应提供了对应说明文案。

## 排序与证据

策略版本为 `tag-explore.v1`，IDF 权重来自当前范围完整公共目录，与私人画像无关。

| 模式 | 默认“题材相关”顺序 |
| --- | --- |
| ALL | 所选题材向量与作品题材的加权余弦 → 公共评分 → Bangumi ID |
| ANY | 所选题材的加权覆盖率 → 加权余弦 → 公共评分 → Bangumi ID |

`sort=score` 先按有效 Bangumi 公共评分降序，再使用上表的关联排序作为同分次序，最后用 ID 稳定排序。原始 0 分按缺评分置后，不冒充确定低分；限定公共评分上界时继续排除未知 0 分。

列表沿用 `recommendations.explore.v1`，返回 `intent=tags`、已应用的规范化 query 和 `selected_seed=null`。证据使用 `selected_tags`，`source=null`，`shared_tags` 仅为实际命中的包含题材；理由如“命中 1/2 个所选题材：音乐”。不伪造参照作品，不显示“你喜欢”，不读取个人分数或改变长期偏好。

详情和 context 继续使用现有探索接口，绑定当前意图、规范化查询、策略、目录、内容范围、用户、记录状态与隐藏反馈。列表与严格详情证据相同；想看操作确认后的完整详情刷新可以反映新的已有状态，但不延长原上下文有效期，不再排序，也不跳过包含 / 排除、类型、年份、评分或隐藏约束。

## 范围、缓存和兼容

- 默认安全范围；主动包含 NSFW 时使用现有总开关、当前审核和永久有效规则。未知分级、未通过当前审核或资料变更导致审核失效的作品不会进入数量、列表或详情。
- 续页仅发送游标，恢复已签名意图，不重排或重建全量特征。混入条件、错误用途、他人游标、篡改、到期、策略 / epoch 变化均拒绝；有效单番快照仍使用原来的策略与校验逻辑。
- 数量仅复用公开目录特征缓存，查询和证据不进入跨用户缓存。当前目录指纹在事务内读取，响应发送前再次校验；直接 UPDATE 造成的晚到变更也返回上下文变化。
- 公共缓存故障可按现有策略回源；限流基础设施整体故障或数据库故障明确不可用，不伪装成零结果。
- 能力接口的 `supported_intents` 现为 `similar`、`tags`，并公布选项合同版本；前端能力适配同时更新，继续兼容旧服务端仅公布 `similar` 的情况。
- “按标签找”的导航仍为不可用，等待 11E 实装界面后再接通；生产 `RECOMMENDATION_EXPLORATION_ENABLED` 默认值仍为 false。无新业务表、数据库迁移、生产环境变量或作品审核变更。

# C1：月度／自选时间段回顾的统计与只读接口

## 阶段边界

C1 已完成私人统计基础和接口，复用现有观看轮次与事件，不新增数据库表、迁移、依赖或定时任务，不创建报告快照。回顾是基于当前有效历程实时计算的结果。

本阶段没有新增回顾工作区页面；C2 再提供“手账｜观看计划｜回顾”、日期选择、摘要卡、作品清单与感想界面，C3 完成展示导出及完整验收，年度展示后续扩展。

同步移除预览详情系列区的关联管理／前往核对快捷入口，保留系列资料查看、页头“核对标准作品”和编辑详情“管理标准作品关联”。预览可查看、编辑可管理的边界不变。

## 日期与事实口径

统计只使用明确填写的实际日期，不使用作品开播日期、添加／修改时间、事件录入时间、计划日期反推观看日。

| 日期与区间关系 | 归属 |
| --- | --- |
| 原日期的完整可能范围包含在选择区间内 | `definite`，计入摘要 |
| 仅部分相交 | `uncertain`，只进“可能相关”明细 |
| 日期为空 | `undated`，只进全账号日期待补充明细 |
| 无相交 | 不进入本期明细 |

复用 `YYYY`、`YYYY-MM`、`YYYY-MM-DD`。例如 `2026-10` 可以计入整月回顾，不能确定属于 10 月 10—20 日。只知道 `2026` 的事实不能直接分配到某个月。返回原日期、精度和明确标注的可能范围，不将范围端点当作实际观看日。

默认以 Asia/Shanghai 的当前自然月为完整区间；自选起止均为真实的日级日期，含两个端点，单次最多 366 天。月份和自选区间互斥，不接受手账外层搜索、标签、年份或用户参数。

### 有效轮次

- 开始里程碑读取当前有效轮次的 `started_on`。日期未知的在看／搁置／看过基线只归入待补充。
- 完成里程碑须该有效轮次当前状态为 `completed`，读取 `completed_on`。状态已更正为未完成时，即便旧完成日期仍在，也不统计为完成。
- 作废轮次不参与。按有效轮次顺序，第一轮之后属于重看；作废轮次的编号空洞不增加重看数量。
- 作品按本人私人记录 ID 去重，轮次分别计数。不按名称或标准作品编号猜测合并。两轮完成同一作品为 1 部作品、2 个完成轮次。
- 更正日期后，里程碑随有效轮次日期移动；不再重放旧事件快照增加一个旧日期的开始／完成。起止日期跨月不意味着中间每个月都发生观看。

### 事件与感想

`note`、`memory` 根据自身 `occurred_on` 归属。状态／进度操作附带的文字也保留为感想事实，标注原事件种类，不单凭文字增加观看或完成数量。它们的日期与轮次日期分别保存，更正轮次日期不会改写原事件中独立填写的感想日期。

明确填写实际日期的在看正向进度、暂停、恢复形成额外观看足迹。倒退进度、仅修改总集数、普通无日期编辑／导入不被当作额外观看。开始和完成足迹使用上述有效轮次，避免重复计数。轮次备注随里程碑展示，不再额外算成一次随记。

撤销事件及其目标事件不形成回顾事实；作废轮次上的事件排除。清空后旧内容不保留，日期未知基线不伪造当月观看。删除作品或恢复完整备份后重新计算。

### 评分与元数据

本期完成轮次评分只使用这些轮次的有效 `rating`，保留 `rating_origin`，按有评分轮次等权计算平均值，返回样本数与缺失数，不用当前综合评分补缺。更正轮次评分会反映到实时回顾。

作品名、海报、季度、当前状态与综合评分标注为 `current_journal`，不是当时的资料快照。海报使用实际保存文件或原始 URL，不换域名、不下载图片。当前综合长评不伪装为本期随记。

首版不计算观看时长、累计观看集数、连续打卡、当时标签偏好、历史计划完成率或当时的优先级。

## API 契约

仅认证本人 GET，可读自己的全部私人记录，不提供公共／他人回顾；读请求不物化轮次、不修正资料、不更新历程或计划。

| 接口 | 用途 |
| --- | --- |
| `GET /api/watch-review/?month=2026-10` | 全范围摘要及归属覆盖情况 |
| `GET /api/watch-review/?start=2026-10-10&end=2026-10-20` | 自选区间摘要 |
| `GET /api/watch-review/entries/?month=2026-10&section=works&page=1&page_size=20` | 稳定分页明细，附同一数据快照的完整摘要 |

契约 `journal.watch-review.v1`，口径 `actual-date-contained.v1`。通用响应：

```json
{
  "contract_version": "journal.watch-review.v1",
  "policy_version": "actual-date-contained.v1",
  "period": {
    "mode": "month", "start": "2026-10-01", "end": "2026-10-31",
    "timezone": "Asia/Shanghai", "end_inclusive": true
  },
  "generated_at": "...",
  "snapshot": "账号绑定的读取凭据",
  "counts_scope": "owner_all_records_selected_period",
  "live": true,
  "metadata_basis": "current_journal",
  "summary": {},
  "coverage": {}
}
```

摘要字段：`started_works / started_rounds / completed_works / completed_rounds / first_completed_rounds / rewatch_started_rounds / rewatch_completed_rounds / notes / memories / viewed_works / related_works / activity_facts / completed_round_rating`。其中 `notes` 已包含 `memories`，不可再相加；`related_works` 包括仅有感想的作品，`viewed_works` 只按观看足迹去重。所有摘要来自完整选择区间，与明细分区、当前页及分页大小无关。

`coverage.uncertain` 为与所选区间相交的粗日期事实／作品数量；`coverage.undated` 为本人全部历程的未知日期事实／作品数量，不能称作本月漏记数量。两者均不计入确定摘要。

明细 `section`：

| section | 返回单位 |
| --- | --- |
| `works`（默认） | 本期有确定相关事实的作品，去重；附事实数、种类数量与原精度的最近相关日期 |
| `started` / `completed` | 本期开始／完成的轮次事实 |
| `rewatch` | 本期重看完成的轮次事实 |
| `activity` | 本期开始、完成、明确正向进度、暂停与恢复事实 |
| `notes` | 本期随记、补录及操作附带感想 |
| `uncertain` / `undated` | 上述两类日期待核对事实 |

明细还返回 `count / count_unit / page / page_size / next_page / results`。`page_size` 为 1—100，默认为 20。作品条目为 `entry_type: work`，事实条目为 `entry_type: fact`，两类均附当前作品摘要。事实 ID 由私人记录、轮次或事件版本构成，不输出完整事件快照、操作 UUID 或请求摘要。录入时间仅供来源核对，不能参与实际日期归属。

## 一致性、权限与边界

PostgreSQL 采用数据库强制 READ ONLY、REPEATABLE READ 快照，SQLite 测试使用 query_only。账号作品、轮次、事件在同一快照读取；即便同时发生完成操作，也不会拼接旧主记录与新轮次。

`snapshot` 签名绑定账号、区间、口径与全部相关源数据指纹，15 分钟有效。翻页必须携带首次返回的凭据；首个明细页也可使用摘要返回的凭据。跨账号、换区间、过期、资料变化均返回 `409 watch_review_changed`，C2 应重新读取摘要和第一页，不将两份结果拼接。凭据不会在翻页时延期。切换分区可以沿用同一凭据。

资料指纹覆盖相关当前作品字段、轮次、事件、更正、清空和恢复边界；使用保存文件名而非会过期的图片签名 URL。仅改计划不会把安排日期带入观看回顾，也不会使无关的回顾凭据失效。

三个有界批量查询读取源数据，不逐条请求历程；摘要不解析海报 URL，明细只为当前页作品解析海报。单账号上限为 10000 条作品、50000 轮、100000 事件，超过任一上限或数据库失败返回 503，不返回截断后的统计。仅允许完整计算，后续有实际超大账号需求时再扩展聚合方式。

所有响应（包括错误）为 `private, no-store`，按 Authorization／Cookie 区分。未知、重复、矛盾或无效日期参数返回 400，未认证返回 401，写方法返回 405。

真实本地浏览器回归验证列表／海报墙预览详情均无关联管理快捷入口，编辑详情入口仍正常，页头入口、观看历程／安排、遮罩关闭、手机布局及关联更换撤销继续可用。

无需新增迁移，更新后端及前端即可；数据库仍须已应用项目现有迁移。仅使用隔离配置、本地专用 PostgreSQL 与合成账号，未操作生产数据。README 按 C1 已完成、C2／C3 与年度展示待开发同步标记。

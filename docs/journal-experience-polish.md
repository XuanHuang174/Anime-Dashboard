# 手账、观看历程与回顾体验修整

## 展示与交互

- 桌面顶部：预览为“个人手账 / 追番记录”，编辑为“个人手账 / 追番管理”。
- 回顾顶部采用观看计划的标识、标题说明与右侧操作布局。进入工作区播放短动画，刷新不重播，遵循减少动态效果设置。
- 推荐观看安排弹窗在路由主题容器之外挂载时也拥有独立主题作用域，提供取消、关闭和底部主操作；原有先加入手账、再设置计划的流程保留。
- 长图默认适应预览宽度，支持原尺寸查看；预览高度随比例调整，关闭入口与操作区固定。独立导出区域保持原尺寸、完整分页和冲突校验。
- 列表／海报墙使用绘制前初始化和动态节点登记。入场期间单独控制透明度与位移，结束后恢复悬停效果；数据刷新不重新隐藏已经展示的节点。开发 StrictMode、动态添加占位和减少动态效果模式均有对应处理。

## 进度与轮次

编辑详情的在看、看过、搁置均显示已看与总集数，切换状态保留填写值，不自动清零或补满。历程记录进度及轮次更正都提供只读“话数情况”，按作品资料原文展示，不推断成整数总集数。

`update-round` 增加可选 `watched_eps`、`total_eps`：当前轮同步当前手账，历史轮只修改该轮。观看状态、起止日期、综合评分及未改动的完成评分快照来源保持不变；总集数 0 为未知，已知时不能小于已看集数。完成状态可保留部分观看集数。

更正仍记录为资料更正，不伪造实际观看日期或新增观看活动。现有并发版本、操作幂等、事务回滚、撤销和 JSON 备份校验继续生效。轮次状态不变时，观看计划阶段及回顾开始／完成计数不因集数更正而改变。旧资料不批量推定或填充。

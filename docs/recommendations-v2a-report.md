## 年份能力与路径边界

本轮没有把年份能力偷偷加入 V2。旧 `rank_context` 两臂的年份探针明确“不支持/未执行排名”；独立复用现有 V1浏览筛选函数生成公共资格预览，绝不把预览结果输入 V2。生产 V1增强9年份筛选未被关闭或改变。

最终轮公共资格预览：安全且有合法身份目录28,636部，其中2020—2026年条件匹配6,886部；缺失/非法年份5,029部不会视为符合该区间。这是公共筛选预览计数，不是V2返回数量。

实际观察阶段包括合格集合、400池、水合、当前复核、返回120、展示证据和Top10；早期安全/类型/评分/排除/题材是同一快照的逻辑普查，不冒称已重排原引擎物理步骤。Top10指离线切片，不是前端曝光埋点。

## 修复和关键证据

1. **慢网不延后本地到期**：原页面在探测完成后安排下一轮检查，长时间等待可能拖延到期处理。现在到期计时独立于网络，20 秒探测超时取消，30 秒间隔；定时器测试验证未完成请求不会阻塞到期。
2. **旧响应不污染当前范围**：客户端丢弃已取消响应和早于当前有效范围的异版本结果；同版本并行结果不被误丢弃。取消后的迟到成功不再把下一次合法探测误判为授权丢失。
3. **真实锁竞争**：四项新增测试确认独立后端连接处于 PostgreSQL `Lock` 等待，再提交用户撤销、作品审核撤销、反馈资格撤销或管理员权限变更。解锁后的请求分别返回 409/403，不写入垃圾记录、不覆盖私人字段。
4. **回退不能复活旧凭据**：审计关闸并重开后，旧游标和详情凭据仍为 409；旧开启请求重放只返回当前状态，不再开闸。部署紧急关闭后，先持久关闸再重新部署／开启的路径已验证。
5. **到期与安全复核**：资格自然到期无需计数递增也拒绝读写；作品审核到期或被改为未知分级后，暖快照失效、详情不再返回。撤销隐藏不能绕过这些限制。
6. **默认路径保留**：安全 V1 排序／理由对照、用户隔离、个人 0 分和长评／标签零覆盖、幂等加入、反馈、身份核对、详情和资源会话相关既有测试继续通过。没有修改排序规则、开启 V2 或改变授权定义。

前端新增 10 项为可执行的时钟、Promise、AbortController 和客户端逻辑测试，其中页面接线为源码合同检查。没有将其称为真实浏览器渲染、手机端或线上慢网验收。

## 部署与回退工具

- `scripts/verify_recommendation_controlled_deployment.py`：部署确认后，绑定一个明确授权账号，复用 M2 关闭态接口验收，可额外只读检查模块 3 开关、匹配构建的前端字节。
- 固定站点／40 请求预算／禁止重定向／仅登录 POST；无数据库导入、无业务写入、无开闸或账号扫描入口。6 项模拟 HTTP 测试锁定这些约束。
- 完整命令、人工检查及持久关闸后再启用流程见 [M3 发布与回退清单](recommendations-controlled-m3-release-checklist.md)。

## 遗留与未验项

- M3 部署后授权账号只读接口、页面及确切构建资产字节比对待完成；M2 的网络连接重置不能据此记为已经解决。
- 生产真实成人作品、资格与作品撤销、关闸写入演练均未执行；须另行明确批准账号、公共目录作品和时间范围。默认继续关闭、保持 V1。
- M2 观察到首批／详情跨网较慢仍为待定位项。本次只修复超时韧性与期限边界，未做线上 SQL／计算／负载测量，不宣称提速或性能全面达标。
- 浏览器后台冻结可能暂停所有 JavaScript；恢复执行时检查期限，后端每次请求照常复核。周期探测不是跨网络的零延迟撤销保证。
- 环境变量单独 False→True 不产生持久历史版本；重新启用前必须在模块 3 关闭一次数据库开关，不能恢复旧控制版本或清空审计。
- 既有前端大包告警保留，不在本阶段顺带重构打包或切换算法。

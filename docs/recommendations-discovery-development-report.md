## 3. 评分偏置与重排适配发现

每账号基础分最高 24 行的均值：

| 统计 | 参考/保护型 V2 | 新评分候选 |
| --- | ---: | ---: |
| 不同题材组合数 | 3.385 | 5.462 |
| 与某部训练来源题材集合完全相同的行数 | 24.000 | 8.308 |

这支持“旧评分偏向完整来源题材集合”的假设；并不表示此类作品天然无效。新公式改变了基础分分布，原重排惩罚不再能维持所需多样性。

发现类最终前十名统计：

| 指标 | V1 | 参考/保护型 V2 | 新评分候选 |
| --- | ---: | ---: | ---: |
| 题材关联代理均值 | 0.629799 | 1.000000 | 0.645256 |
| 两两题材 Jaccard 均值 | 0.347656 | 0.135731 | 0.504839 |
| 重复题材集合比例 | 0.092308 | 0.123077 | 0.184615 |

新候选的题材关联代理略高于 V1，但题材重复度门槛失败。该代理不是喜欢概率，也不能代替留出命中。旧 V2 的代理为 1 并不代表完美推荐，反而需要结合本轮完整集合偏置看待。

本次只做评分单变量实验，不能由此断言某个尚未测试的融合权重或重排方案必然有效。后续应考虑整体画像与来源作品两个视图如何共存，以及重排强度如何与基础分尺度适配，而不是直接丢弃其中一个视图，也不是按账号/作品 ID 保留命中。

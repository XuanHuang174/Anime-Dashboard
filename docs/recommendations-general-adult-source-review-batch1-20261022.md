核查日期：2026-10-22。范围：上轮 521 项技术候选中，被元数据盘点归为“未命中当前风险排除、但只有旧版批准”的 5 个 Bangumi ID，按 ID 升序固定选取。

**这是公开资料核查报告，不是内容批准记录。首批新增确认通过 0 项；未修改数据库审核、候选策略或线上开关。其余作品尚未完成外部资料核查，不能据本报告声称已审核全库。**

## 方法与可信度

1. 仅通过现有 Bangumi ID 读取对应公共目录的准确名称、类型与季度，使用 PostgreSQL 强制只读事务。不以标题相似度判断同系列、续作或身份。
2. 查阅 Bangumi 官方文档、相关条目入口、维基百科文字资料、发行方公开新闻及国立国会图书馆书目。
3. 书目可用于核对名称、出版者、载体及年份，**不证明人物均为成年人**。图书馆“对象利用者：一般”也不能解释成内容安全认证。
4. 维基百科可提供版本和角色设定线索，但不自动取得发行方认证的效力；涉及原作资料时须保留与具体动画版本之间的映射和不确定性。
5. NSFW、18 禁及面向成年观众的标记，不能单独证明涉及性内容的人物均为成年人。缺少年龄或风险资料不视为通过。
6. 没有下载封面、图片、视频或试看片，没有读取私人手账，也没有向外部服务发送私人数据。发行方页面只读取可公开获取的文字，没有提交年龄确认或访问购买/媒体资源入口。

## 来源与证据边界

### Bangumi 资料入口与访问情况

- [官方 API 文档仓库](https://github.com/bangumi/api/blob/master/open-api/api.yml)：描述部分 NSFW 内容仅向授权用户提供，未授权时可能返回 404。
- [官方公开 Wiki 数据归档说明](https://github.com/bangumi/Archive)：将 nsfw 定义为是否含成人内容；没有提供“性内容人物均成年”的现成布尔认证。
- 实际尝试读取本批各 ID 的条目入口：多数返回未找到条目的通用页面，另有一次抓取失败。没有据此断言条目已删除，也没有规避访问控制。
- 本机没有配置 `BANGUMI_ACCESS_TOKEN`。本轮没有创建、借用或提取其他凭据，没有调用镜像以规避受限访问。
- 官方归档说明本轮仅用作字段定义来源；没有下载整个归档或声称从中核验了全部角色。

## 原固定对照中止

完整比较运行在核对历史站点锁时返回 `Frozen cohort/catalog/private inputs drifted; stopped, no reselection`，发生在推荐排序与命中计算前。后续只读诊断确认：

| 项目 | 结果 |
| --- | --- |
| 活跃账号 | 原 81，当前 81 |
| 目录版本 | 与原冻结值相同 |
| 原冻结账号 | 17 个均仍存在 |
| 原账号画像输入 | 1 个发生变化 |

本报告不猜测该用户修改了哪个私人字段，不导出账号、标签、评分或作品身份。没有重选留出目标、恢复/修改用户数据、重签历史锁，也没有将旧的 52 目标改称独立验证集。不能把上一轮 1/3/3/2 命中结果当作本轮双视图的结果。

最初中止发生在新增聚合停止报告功能之前，所以该次尝试没有 `comparison.json` 或签名停止报告；漂移聚合确认来自独立只读检查。后续相同中止会写入 `stopped.json`，仍不继续排序。

**后续质量复测需要先明确新一期输入冻结方案**：保留旧锁和失败结果，固定同一批账号与同一批目标身份；若目标已不再符合自然样本条件，应明确记录不可评估，不静默补选。此新快照仍是开发回归，不是独立验证。当前没有执行该刷新。

## 当前输入性能诊断（不是冻结质量对照）

为避免将输入漂移误当作算法效果，另行运行 `profile_recommendation_discovery`：预先规定只取原冻结账号中主键最小的一个仍有效账号，使用其当前画像，零留出目标，五臂各两次。事务强制只读、重复读；结果摘要一致；不输出卡片、来源作品、用户标识、私人标签或长评。

| 执行臂 | 两次引擎耗时 ms | 两次进程 CPU ms | SQL/次 | 候选/次 |
| --- | --- | --- | ---: | ---: |
| V1 | 774.643 / 419.710 | 156.250 / 171.875 | 1 | 400 |
| 参考 V2 | 8302.033 / 7153.682 | 203.125 / 218.750 | 5 | 400 |
| 保护型 V2 | 9592.223 / 10825.550 | 203.125 / 234.375 | 5 | 400 |
| 整体画像替代候选 | 12397.867 / 13523.332 | 203.125 / 203.125 | 5 | 400 |
| 双视图候选 | 11104.888 / 8615.613 | 296.875 / 250.000 | 5 | 400 |

V2 系共 8 次调用的公共目录指纹扫描平均 **8261.269ms**，占其引擎总时长合计的 **81.08%**；扫描单次 **6309.383–10852.452ms**。其余阶段为两次事务只读/隔离检查、一次候选水合、一次来源安全复核，无变化行补读。

同一诊断的公共目录 EXPLAIN：28,636 行；服务端规划 **2.264ms**、执行 **92.443ms**；客户端 EXPLAIN 总时长 **226.994ms**。三次 `SELECT 1` 往返 **127.747 / 118.065 / 137.490ms**。此前独立漂移排查时的 `SELECT 1` 为 **359.021 / 476.594 / 1103.953ms**，体现链路时长波动，但不混入本次五臂平均数。

定位结论：在本次观测中，**大量公共目录指纹结果的读取路径**是首要等待点，而不是融合评分 CPU。EXPLAIN 返回的是小型执行计划，不传输完整 28,636 行结果，因此与真实扫描的差值包含传输、驱动和客户端路径，不能当作纯 RTT，也不能仅据此认定 Neon 服务端或网络某一方是唯一原因。

这些数据不是 Render/HTTP 首屏测量，不是全站性能分布，固定顺序且每臂仅两次，不能用跨臂差值宣布融合性能收益。原 **5000ms / 6 SQL** 门槛未放宽；本次 V2 系时长均超 5 秒，不具备上线性能通过证据。下一步应优先研究如何减少每请求的全量目录指纹传输，并严格保持当前安全、目录变化发现与排序语义，再重新测量。

# M2：受控推荐链路与模块 3

## 本阶段边界

这是人工访问授权，不是年龄核验或全球合规证明。没有新增外部核验服务、证件上传或 AI 调用。未操作任何生产审批、作品审核、开关或手账数据。线上 V1 不切换为 V2，默认仍为安全范围。

## 放行条件（必须同时成立）

1. 部署能力 `RECOMMENDATION_RESTRICTED_CONTENT_ENABLED=True`，算法仍为 `content.v1`，V2 浏览未开启。
2. 模块 3 的独立数据库总开关开启。无数据库状态视为关闭，GET 不建行。
3. 当前账号有未过期的 M1 人工访问批准，且账号仍有效。管理员身份不能替代用户批准，不能批准自己的申请。
4. 本次请求显式 `content_scope=include_adult`。默认或重新进入页面为 `safe`，没有长期偏好写入。
5. 对于成人作品：有当前资料指纹、当前规则、未过期且排除项确认完整的逐作品审核。未知分级始终不放行。

`include_adult` 是安全作品与合格受控作品的合集，不是“只看成人作品”。仍须有有效题材、真实喜好关联，并继续受类型／评分／年份、手账隐藏、反馈排除约束；范围过滤先于 400 候选截取。

## 管理员模块 3

保留原 `/admin-dashboard/module-3` 路由，入口更名为“受限内容管理”。

- 查看部署闸门、后台总开关和版本；开／关必须填写原因、确认，并提交 UUID 与预期版本。
- 按待审批、已批准、已拒绝、已撤销或全部分页读取人工申请；不会读取用户手账评分、长评或标签。
- 逐账号读取 15 分钟有效的服务端签名凭据，再明确批准／拒绝／撤销。复用 M1 服务、用户行锁、版本及操作回执；批准最多 30 天。
- 版本冲突要求重新读取。网络结果不确定时保留原操作凭据，重试原操作，不新建另一决定。
- 作品逐条审核继续复用 Django 后台“推荐作品内容审核”，不另造第二套审核系统。总开关审计为只读、无新增／修改／删除／批量操作。

接口均仅限实时核验的超级管理员，使用正常登录及现有节流：

| 接口 | 用途 |
| --- | --- |
| `GET/POST /api/recommendations/admin/control/` | 读取／确认总开关 |
| `GET /api/recommendations/admin/applications/` | 申请分页 |
| `GET/POST /api/recommendations/admin/applications/{user_id}/` | 签名读取／逐账号审批 |

## 用户页面

- 筛选面板继续使用原生 Dialog、独立滚动正文与固定底部“应用筛选”。
- 未申请／待批准／服务关闭仍展示简短申请提示；仅有效批准且服务开放时出现“包含 NSFW 标记作品（本次浏览）”，默认不勾选。
- 勾选只是草稿。取消／Escape 不写入、不应用；应用才更换整个浏览会话。条件摘要可单独移除，恢复默认回到安全范围。
- 卡片、详情、分页、加入、反馈、隐藏清单与身份确认均携带当前范围，不能拿成人游标在安全范围续页。
- 成人作品显示 `NSFW`，封面只用现有中性占位，不返回原始或 CDN 封面。评分语义不变。

## 失效与隐私

范围上下文包含账号资格版本、审核版本、总开关版本、有效审核集合指纹、最早到期时间和用户绑定 HMAC；这些字段进入快照和证据合同。

- 每个请求重新校验；只读快照结束后，再校验当前授权和实际返回作品／证据来源的安全状态，拦住计算过程中发生的分级变更。
- 游标到期不晚于授权或当前有效审核的最早到期时刻。
- 成人与安全公共特征缓存分命名空间，不缓存私人画像／结果。审核、目录、授权、总开关变化使旧上下文失效。
- 写入锁顺序：用户 → 受控总开关 → 作品；锁等待后再次核验。关闸可与正在进行的写入线性化，已提交写入不会被伪报为未提交。
- 关闭／失效会取消旧请求，清掉详情、资源与游标，从安全范围重新读取。网页在受控范围前台时每 30 秒做轻量上下文检查，回到前台也检查；准确到期计时也会退出。没有声称推送式的零延迟撤销：服务端每请求立即拦截，已渲染页面依靠检查／到期计时清除。
- 自动画像及来源作品始终只用安全作品；即使已授权，成人作品也不会成为画像样本。
- 成人“加入想看”仍幂等、不覆盖已有记录；新公共资料默认非公开，并且跳过自动展示发布。私人评分（含 0 分）、长评、观看状态、原标签不变。
- 身份核对仍是用户逐条选择并确认，签名绑定范围；无模糊标题自动合并、无续作推断。

## 迁移与部署（保持关闭）

先备份，再在正常部署流程执行：

```text
python manage.py migrate
```

新增 `0010_controlled_serving_m2` 只建总开关和审计表，不初始化开放状态，不修改原用户授权、反馈或手账。前后端部署后，先保持：

```text
RECOMMENDATION_ALGORITHM_VERSION=content.v1
RECOMMENDATION_V2_BROWSE_ENABLED=False
RECOMMENDATION_RESTRICTED_CONTENT_ENABLED=False
```

模块 3 应显示部署关闭／服务关闭，不能从页面越过部署闸门。普通推荐仍可正常读取。待下一轮明确的上线放行与验收，再由操作者决定是否开启部署闸门、逐作品审核、处理用户申请，以及最后开启后台总开关；不是部署本提交就自动开放。

只读验收脚本（部署确认后由操作者输入授权账号；唯一 POST 是正常登录）：

```text
python scripts/verify_recommendation_scope_deployment.py --deployment-confirmed --expected-account <授权账号>
```

该脚本适用于默认关闭验收，禁止用它执行开闸、审批、反馈、加入、偏好或身份写入。生产真实开放状态及授权成人可见性须另行确认，不把隔离合成测试冒充线上验收。

## 安全回退

优先模块 3 关闭后台总开关；紧急情况下将 `RECOMMENDATION_RESTRICTED_CONTENT_ENABLED=False` 并重新部署。保持 V1，不必切换算法或清空用户数据。

不要回滚数据库或删除审批／反馈／手账／审计。关闭后受控范围的新请求拒绝，旧游标／证据不能续用，前端回到安全会话。需要代码回退时保留增量表即可。无需清空全站缓存；只允许失效本功能的公共受控缓存命名空间，不清私人数据或全站缓存。

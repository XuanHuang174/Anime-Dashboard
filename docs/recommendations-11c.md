# 扩展 11C：单番相似前端

日期：2026-10-24。状态：已实现并完成本地隔离验收。生产探索开关仍默认关闭；标签模块留给 11D / 11E，发布验收留给 11F。

## 交付呈现

- 标题栏使用已确认的三个入口：`个性化推荐 · 当前`、`单番相似`、`按标签找`。当前入口用青色，个人推荐的“为你发现 / 电波契合 / 换一种口味”和风格工具保持在下一层。
- 三入口由能力接口控制。探索开启时放行“单番相似”；“按标签找”显示尚未开放，直接访问也明确提示不可用。窄屏三入口各占一列。
- 单番页支持本站作品名称、Bangumi ID 和严格的 subject 链接搜索；最多显示 15 个候选。无有效题材的作品说明原因并禁止选为参照。
- 选中作品后显示参照条、共有题材依据、首推卡片、“本次参照”侧栏和“还有更多”网格。更换、清除、筛选、批内追加和换批均可使用。
- 筛选复用类型、年份、公共评分、隐藏手账记录和本次 NSFW 开关，不混入个人推荐风格或口味偏好。
- 详情复用原有模态框、想看操作、隐藏反馈与撤销、隐藏清单、身份核对和资源抽屉。详情提供“以这部找相似”，不会自动加入手账或修改偏好。
- 私有手账的预览详情和编辑面板新增“找相似”；共享手账没有此入口。编辑草稿或海报尚未保存时显示“保存后找相似”并禁用跳转，避免离开时丢失未保存修改；不会代用户保存。
- 加载单番数据时使用“正在读取参照与相似作品”，不宣称读取个人口味。GSAP 继续使用文档生命周期内首次入场和减少动态效果策略。

## 入口与记录身份

保护路由扩展为 `/recommendations/*`，个人推荐仍是 `/recommendations`，单番链接是 `/recommendations/similar?seed=<BangumiID>`。

手账记录主键通过页面内部状态传递，不放入可分享 URL，也不当作 Bangumi ID 使用。新增只读接口：

```text
GET /api/recommendations/explore/record/<record_id>/
contract_version: recommendations.explore.record.v1
record_id / identity_state / bangumi_id / content_scope_context
```

接口只查询当前用户的指定一条记录，复用有效直接 ID、别名指纹和冲突规则，不读取评分、长评或私人题材。别人的记录返回 404，未登录返回 401；关闭探索时返回 503。不接受额外用户或作品参数。

有效关联进入对应 seed；未关联或关联失效打开现有身份核对工具，并定位到该条记录。范围不允许或未知分级时提示检查筛选，不自动放开 NSFW。身份核对完成后重新解析，不自动猜测片名或合并记录。

## 会话与失效处理

- 两个模式的条件、批次、已加载卡片和滚动位置只留在当前登录工作区的 React 内存中。切换时卸载旧页面，取消搜索、续页、详情、资源和操作会话；返回时恢复并校验上下文。刷新或更换账号会清空工作区。
- NSFW 选择由同一个工作区持有，切换模式不会自行取消。真正的内容范围拒绝仍会回到安全范围；普通 `exploration_snapshot_changed` 只标记探索列表失效。
- 探索结果和详情使用独立 mapper，严格校验查询、参照身份、共有题材、证据版本、内容范围、数量、游标结构和有效期；不借用个人画像证据，不接收来源私人评分，不显示喜欢概率。
- 每次续页仅发送游标。前端检查快照 ID、有效期、条件、版本、参照特征和批次位置；服务端跨秒重新签发同一上下文时允许令牌字符串变化。
- 返回页面、窗口重新可见、跨页变更通知、每分钟和到期时使用探索 context 接口校验；不会为单番探索读取个人 profile/context。失效后保留布局、清空旧证据并禁止旧结果继续操作，等待明确重新探索。
- 加入想看成功后立即丢弃整个旧详情和资源会话，使用原查询的详情上下文重新读取完整详情。新详情可以继续使用；旧列表保持失效直到重新探索。不重复提交已确认的 POST。
- 隐藏 / 撤销后更新结果和清单。隐藏清单保留在原面板，未确认操作可以通过原有幂等重试确认。

- 前端：331 项通过，涵盖原有推荐功能及新独立证据、异常响应、迟到请求、批次、恢复、加载文案、深链接和导航。
- 后端：原相关完整回归 190 项通过；随后增加跨秒上下文重新签发测试，11C 专项 7 项通过。两者合计覆盖 191 个不同测试。
- Django 实际返回的安全范围列表 / 详情、永久 NSFW 范围列表 / 详情，以及跨秒续页，通过 Node 调用生产前端 mapper 校验，避免只用前端手写夹具推断合同兼容。
- 私有记录入口验证：有效直接关联、有效别名、失效别名、未关联、拒绝他人记录、禁止额外参数、关闭能力、NSFW 范围；SQL 检查不读取评分 / 长评 / 私人题材，也不写库。
- Django check 通过，makemigrations --check --dry-run 无变化；前端生产构建通过。原有主包超过 500 kB 的提示仍存在。
- 浏览器使用本机合成夹具，全部 API 拦截，不访问生产数据。真实 CSS 视口 1440 / 390，以及默认窄面板下核对导航、侧栏、网格、名称 / ID 选择、无题材禁选、详情、想看、资源抽屉、更换参照、24 部追加、跨模式保留、隐藏 / 撤销、私有记录入口和年份筛选。中断期间自然到期后，重新探索恢复正常。

本地夹具：`frontend/tests/fixtures/explorationHarness.html`。可使用 `?viewport=1440` 或 `?viewport=390` 在 iframe 中形成真实 CSS 视口；它不进入生产构建。资源搜索仅检查抽屉与错误回退，不执行外部下载；NSFW 使用真实后端隔离测试及合同测试，不通过浏览器自动执行年龄确认。

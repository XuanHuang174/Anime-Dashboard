# 扩展 12D：直接关联分区与三种探索的关系标识

日期：2026-10-25。按 [扩展 12 方案](recommendations-extension-12-plan.md) 实现。本轮交付默认关闭的独立策略和界面，没有修改 Render 环境变量、导入生产关系或直接放行原 V1/V2 排序。

## 最终呈现

单番相似在参照与筛选栏下增加“本作已确认的直接关联”，再展示“其他题材相近作品”及原有首推、更多与批次操作。关联区展示续集、前传、总集篇、全集、番外与分支等明确关系，提供关系详情入口。普通筛选、隐藏反馈及隐藏已有记录对关联区同样生效，但关系区不要求与参照共有题材，不会伪造题材相似证据。

日期、发行形式与关系分开显示：剧场版不会被自动标成总集篇，OVA 不等于番外。关联区文案说明只依据直接关系，不推断整个系列或观看顺序；空结果、未获取、过期、最近更新失败和部分资料都有区别。没有记录不写成没看过。

三种推荐的卡片在公共评分下增加紧凑关系标识，例如“续集 · 相对《第一季》”，点击进入有依据的来源关系页，并保留原筛选、已加载批次和位置。标识描述一条关系，不给作品强制分配全局互斥类型。一部作品可以同时是某作的总集篇，又与另一作存在其他关系。

按标签找与个性化推荐保持原候选及排序；不同季条目仍可同时命中。没有标识只表示这次没有返回可展示事实，不代表独立作品。续作提醒留给 12E，没有增加一级导航。

## 关系策略

策略版本为 `series-explore.direct.v1`。沿用 12B 的当前观察、待复核过滤、人工 replace/suppress/clear 及上游变化后重新复核规则。

- 读取参照的出向断言及其他作品列出的入向断言，保留原始方向。`A → B：前传` 始终表示 B 相对于 A 是前传，不把反向断言猜成另一种关系。
- 故事前后、总集/版本、番外/分支进入独立关联区，同时从题材相似候选中排除。角色出演、世界观、改编、联动、其他弱关联不自动合并成同一连续剧情，也不据此排除题材结果。
- 只处理直接事实。A 与 B 有关系、B 与 C 有关系，不推断 A 与 C 同系列；标题不参与关系推断。
- 所有排除在普通候选排序和 120 条截取之前执行。关联区最多展示 12 部，展示上限不会缩小实际排除集合；250 条关联的合成测试也不会只排除前 12 或前 200 条。
- 关系区自身按发行日期及 ID 稳定整理，未知日期排后；先应用范围、隐藏、已有记录、年份、类型和评分条件，再截取 12 部并报告过滤后的数量。两个区的计数与批次各自独立，关系区不占用 120 条题材相似名额。

图读取只接受当前目录内、两端身份和分级一致且符合本次内容范围的动画。未收录、未知分级、NSFW 未核验或超出范围的两端不返回标题和关系计数。每次最多处理 5000 条相关当前断言及 5000 条最新人工决定；超限明确失败，不通过部分排除后继续填充相似区。人工决定使用按作品对建立的索引，避免逐条全量扫描。

## 合同与快照

| 接口 | 用途 |
| --- | --- |
| `GET /api/recommendations/explore/series/` | 新单番相似，查询字段不扩展；响应 `recommendations.explore.series.v1` |
| `GET .../explore/series/context/` | 校验账号、筛选、目录、范围、记录、反馈及关系版本 |
| `GET .../explore/series/<id>/` | 独立候选详情，仍使用原题材依据合同；禁止把直接关联冒充相似结果 |
| `GET /api/recommendations/series/annotations/?ids=...` | 一次 1–24 个不重复 Bangumi ID 的只读关系标识，合同 `recommendations.series.annotations.v1` |

旧 `/explore/`、标签探索、原个性化推荐接口保持兼容。题材相似算法和证据仍为 `similarity.v1` / `recommendations.explore.evidence.v1`，额外的直接关系选择策略单独版本化，不把系列关系伪装成新的共有题材。

新快照绑定系列策略、系列版本、相关节点和有效事实摘要；继续绑定原账号、目录、内容范围、查询、本人状态与隐藏反馈。固定的 120 个 ID、24 条批次、12 条页及 900 秒有效期保持原规则，后续请求不重新排名。旧、新合同不能交换游标。关系变化后，分页、前台检查和详情都明确失效；已确认加入想看后的详情允许更新本人状态，但不能趁机延长原快照期限或使用已变化的关系。

系列元数据在发送前再次校验，并沿用私有禁止缓存和内容范围复核。系列版本冲突分别使用 `exploration_snapshot_changed` 或 `series_snapshot_changed`；**关系更新不能被误判为 NSFW 授权失效**。元数据发现系列版本不同，也会使相似分区失效。普通作品的关系链接同样保留当前 `include_adult` 范围，不能按作品自身分级擅自恢复 safe。

卡片关系元数据按当前批次批量读取，无逐卡请求、私人共享缓存或浏览器持久化。账号/范围切换、请求取消、前台检查及范围到期都受控。标签/个性化中的关系服务失败只清除关系标识，不重排原结果；单番分区读取失败不默默退回未分区结果。

## 开关与回退

新能力须同时满足：

```text
RECOMMENDATION_SERIES_ENABLED=True
RECOMMENDATION_SERIES_EXPLORATION_ENABLED=True
```

第二个开关本轮新增，默认 False。单番探索同时要求原探索开关和灰度账号条件有效；能力声明沿用该可见范围，关闭时保留旧合同描述，开启时才附加 `series_exploration` 策略能力。新前端读取能力后才请求分区接口；旧前端继续使用旧接口。

关闭新开关后新接口拒绝旧分区上下文，刷新页面重新读取能力即可回到原探索流程；不会把正在浏览的分区批次与旧排序混用。此开关不修改 NSFW 总开关、审核记录或用户偏好。正式数据、覆盖率、性能及灰度放行仍属于 12F。

# 扩展 13D：人物与制作前端浏览

日期：2026-10-28。承接 [13C 只读接口](recommendations-13c.md)，实现人物与制作的前端入口、标准实体检索、参与作品列表、预览详情摘要与原页保留导航。没有启用线上开关、修改 Render、导入生产资料或增加问卷；三个推荐主导航保持原样。

## 入口与展示

- 个性化推荐／单番相似／按标签找顶部工具区增加次级“人物与制作”入口，带麦克风图标。依据独立 credits capability 展示；声优／公司均关闭或旧服务端没有能力字段时隐藏，不影响既有推荐。
- `/recommendations/credits` 提供“找声优／找制作公司”、姓名／已收录别名／完整 person 链接检索。关闭的种类不能选择；重名以标准人物 ID 区分，最多展示 15 项并提示缩小检索范围。
- `/recommendations/credits/{kind}/{person_id}` 使用白字黑底实体标题，区分当前内容范围确认关联总数与本次筛选数。提供类型、起止年份、评分、隐藏已有记录、排序和稳定加载更多。评分文案沿用“6.0 以下（不含未知评分）”。
- 声优作品卡显示“饰演：…”；公司作品卡显示“参与职务：动画制作”。卡片先显示前三个角色，较长清单和章节来源备注在详情折叠区完整呈现，不解析集数、不推断出演语言或观看顺序。
- 原有三种推荐的详情使用同一 `CreditsSummary`。私人手账只在预览详情接入，编辑窗口和公开详情不接入。私人填写的制作公司文本保留；独立来源确认的标准公司另外显示链接。
- “声优与角色”默认收起，第一次展开请求 expanded=true；收起再展开使用本组件已确认的完整有界清单，不重新请求。明确展示未加载、不完整、最近失败、过期和截断，不能将零条资料解释为“没有声优／公司”。

本轮列表是只读浏览；“我看过的”切换、本人状态交互、作品详情及幂等加入想看闭环按既定分工在 13E 完成。本次没有把 credits context 当作已有推荐 evidence token，也没有展示无法执行的假按钮。

## 导航、缓存和动画

扩展现有系列的保留原页机制。来自手账或三个推荐页的入口保留原路由及其详情、筛选、参照、预览和滚动，人物页在原生顶层 dialog 中展示；返回恢复原页。直接打开路由则正常独立显示，检索到实体再返回仍保留检索词和结果。人物页使用独立懒加载，不变更登录保护。

React 所有的缓存绑定账号会话、内容范围、实体和检索类型；只存当前页面内存，不写 localStorage／sessionStorage 或共享缓存。账号改变销毁页面状态，离开的异步请求取消且不能回填。保留已经加载的分页、已应用条件、未提交筛选草稿及滚动；关闭整个模块／刷新后不保留这些资料。

复用现有 GSAP 控制器，为人物检索和实体页分别记录当前文档生命周期内的入场状态：顶部功能区、检索／筛选区、结果区逐步入场。加载更多和返回不重复整页入场，刷新重置；遵守 prefers-reduced-motion，并在卸载和 StrictMode 重挂载时恢复正常可见样式。私人预览中的摘要放入既有 memphis-modal-piece 动画节点，异步资料加载后另做局部入场。

## 请求与内容范围

前端逐项验证合同版本、内容范围修订、来源证据、实体身份、计数、去重、角色、职务、筛选、过期时间和游标界限。增加真实 Django HTTP 响应到 JavaScript 校验器的跨语言测试。13D 为 13C 作品列表补充明确的 `content_rating` 字段，使前端无需由空封面或其他线索猜测分级；成人封面仍为空。

查询、实体或账号切换取消旧请求。分页只提交服务端 cursor，合并前核对参与关系修订、内容范围、条件、计数、原始到期时间和重复 ID。资料变更或过期保留上次已确认的只读内容并阻止续页；网络不确定性不会冒充权限撤回。明确失去访问资格或模块关闭则清除旧资料。

内容范围沿用既有控制读取器；只有用户应用选择后切换范围。`credits_snapshot_changed` 与 `credits_disabled` 不触发 NSFW 选择重置；真正的权限／内容范围失效继续由原客户端处理。默认 safe，未知分级排除，成人范围必须通过现有服务和逐作品审核，禁止来源封面泄漏。

焦点／前后台切换不重新请求关系列表。页面至多每 60 秒在前台检查一次能力；成人范围仅使用已有轻量 context 检查和独立到期计时。手账／隐藏反馈更新将现有结果标记待重新读取，不逐次轮询人物关系。数据过期、错误和重试均不会修改私人记录或长期偏好。

- 生产构建通过。构建仍提示既有主包超过 500 kB；人物页已独立分包，本轮没有调整整个项目的打包策略。

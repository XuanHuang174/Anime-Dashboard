# C2：私人观看回顾工作区

## 交付与入口

沿用 [C1 的日期、轮次与只读接口口径](watch-review-c1.md)，页头工作区增加“手账｜观看计划｜回顾”。编辑／预览模式均可查看本人回顾，公开手账、共创查看和管理员公开手账审阅不挂载回顾组件，也不发送回顾请求。

手机工作区导航在身份标识下独立一行，避免第三项被右上角菜单遮挡；桌面继续与身份标识并排。保留现有手账、计划入口及计划草稿的离开保护。

本轮没有新增回顾导出或年度展示，继续留在 C3 和后续阶段；不增加后端接口、数据库迁移或依赖。

## 时间选择与展示

- 默认按 Asia/Shanghai 当前月份；支持上个月、下个月、回到本月和自选起止日期。
- 自选区间含起止当天，最多 366 天，校验实际日期、顺序和跨度，不用当地时区计算天数而发生跨月／夏令时偏移。
- 时间表单草稿与已应用区间分别保存。尚未提交时提示“时间选择尚未应用”，原报告标题不跟着输入框变化。
- 切换工作区保留已应用区间、分区、每页数量和未提交日期草稿；重新进入时读取该分区第一页的最新完整结果。账号变化清除旧工作区和详情状态。
- 摘要卡为开始观看、完成作品、重看完成、随记与补录，点击定位到对应分区。完成卡同时说明完成轮次数，不将重看算成新增作品。
- 展示本期完成轮次平均评分、有效样本和缺失数量；不以当前综合评分补缺。
- 作品清单按私人记录去重；开始、完成、重看、足迹、感想按各自事实分页。上下分页与每页 12／24／48 条可选，摘要始终来自完整选择区间。
- 随记保留换行，长文字可展开；补录、轮次评分及评分来源有独立标注。“查看依据”区分实际日期与系统录入时间。

“日期说明与待补充记录”默认折叠。可能相关保留年月／年份精度，不补成某一天，明确不计入确定统计；日期未知来自本人全部历程，明确不是当月漏记数量。空状态使用“暂无可归属记录”，不宣称期间没有观看。

作品名、海报、当前状态与综合评分均标明当前手账资料。使用已有评分展示配置、实际海报 URL 和安全的外链格式；加载失败显示封面占位，不改写原图片地址。

## 查看与管理边界

回顾页面只调用 GET。点击作品或“查看详情”始终打开只读档案，即使手账当前处于编辑模式，也不会直接进入编辑表单。

只有明确点击“补充／更正日期”，或在只读详情中主动前往历程管理，才切换到该作品的编辑历程工作区。回顾页不直接修改日期或状态。返回后保留回顾选择；历程保存通过现有记录刷新键更新回顾。编辑详情中的标准作品关联管理继续保留，预览不恢复该快捷入口。

## 读取与失败处理

`watchReview.js` 提供日期处理、响应校验和只读控制器。页面一次读取 C1 明细接口，由同一响应取得完整摘要、覆盖情况和当前页，避免分别读取摘要和列表导致混用版本。

分区与翻页沿用原签名凭据，验证契约版本、日期范围、全部计数、分页完整性、唯一条目、日期精度、事实归属与同凭据下的摘要一致性。资料变化或凭据过期返回 409 时清除旧结果，只自动进行一次无旧凭据的本区第一页读取；重复冲突明确报错，不无限重试。

新日期／主动刷新开始新一轮读取；读取期间不显示旧列表与新摘要的组合。网络、503 或响应不完整时提供重试，不将部分结果当作完整回顾。旧请求会被中止，并使用请求序号与账号身份忽略迟到响应。回顾数据、读取凭据与日期草稿均只保存在当前组件内存，不写入本地存储或公共缓存。

回到工作区、记录保存、窗口重新聚焦或页面恢复可见时重读，聚焦／可见事件短暂合并。刷新只使用已应用区间，不覆盖尚未提交的日期输入；离开工作区停止请求与聚焦监听。

## 验证与复跑

前端测试增加上海月份、闰年区间、摘要与分页契约、粗日期／未知日期、重复作品、同凭据摘要变化、迟到响应、账号切换、409 有界重读、未提交区间和取消读取等覆盖。全量前端测试、生产构建、Django 检查与迁移漂移检查通过，保留既有大分包提示。

隔离本地 PostgreSQL 的 26 项 C1 专项回归通过。真实本地浏览器在正常／减少动画下验证：三项导航、外层筛选独立、完整统计与分页、长感想、编辑模式中的只读详情、部分相交与未知日期、编辑／预览中显式前往更正、草稿保留、真实资料变更后 409 重读、聚焦刷新、临时错误重试、月份翻页、诚实空状态及公开隐私。覆盖 320／390px 手机、844px 横屏和 1440px 桌面，无页面运行错误；原 B3 浏览器回归也通过。

复跑步骤：

1. 使用 `config.journal_polish_e2e_settings` 应用现有迁移，数据库仅为忽略的 `.tools/watch-history-a3.sqlite3`。
2. 执行 `scripts/seed-watch-review-c2-e2e.py`，每轮创建新合成账号及日期／轮次，不删除旧数据。
3. 启动 127.0.0.1:8000 后端和 5191 前端，在 frontend 执行 `node scripts/test-watch-review-c2.mjs`，按本机配置 `PLAYWRIGHT_MODULE`。
4. 默认减少动画；设置 `REVIEW_TEST_MOTION=no-preference` 验证正常动画。完整重跑前重新生成合成账号，测试会更正一条合成作品名称以验证凭据失效。

令牌、数据库、日志与截图仅位于忽略的 `.tools`。本轮未操作生产数据。上线更新前端即可，后端须已部署 C1 接口；无新增迁移或环境变量。

# 增强 9C：回归与验收记录

日期：2026-10-17。结论：**本地实现与隔离回归通过，当前线上 9B 只读基线通过；9C 部署后的验收尚待执行，不能提前结案。** 线上保持 `content.v1`，未开启 V2、未修改真实评分或其他业务数据。

## 改动范围

- 独立能力合同 `GET /api/recommendations/capabilities/`：登录保护、private/no-store、只允许 V1。
- 关闭增强浏览时返回明确的 `browse_disabled / legacy_v1` 信号；前端丢弃新游标、关闭详情/资源会话并重新读取原有 V1 第一页。普通网络错误绝不伪装成回退。
- 发布代次进入游标及上下文签名；关闭/重新开启均使用新代次，避免旧游标复活。
- 精确目录指纹绑定的短时**公共**特征缓存。不缓存用户画像、私人结果、来源评分或资源搜索；没有调整 V1 排序公式。
- 只读性能命令、部署审计、回退配置生成器、隔离测试与报告。无需新增迁移。

## 自动化矩阵

所有数据库用例使用本机 `test_recommendation_isolated_tests` PostgreSQL，测试设置拒绝生产地址与 SQLite。外部 HTTP 在后端测试中被阻断。

| 场景 | 核验方式及结果 |
| --- | --- |
| 默认均衡与冻结 V1 完全一致 | 三类别全有序结果及首屏证据逐项相等；缓存开/关也相等 |
| 非默认风格有效、类别边界保持 | 数学系数与实际排序用例；无关联作品不因开放档被加入 |
| 类型、分数、年份、隐藏记录前置 | 超过候选截取规模的合成数据；缺失/非法年份及补零月份覆盖 |
| 跨页/跨批去重、重试不跳位 | 全轮遍历、相同游标重复读取、页码/批次/首条主推一致 |
| 用户隔离及上下文失效 | 外来游标、手账/画像/偏好/反馈/目录/规则变化返回 409 |
| 安全及零副作用 | NSFW/未知分级、直接 UPDATE 后旧缓存/快照不可绕过；手账逐字段不变 |
| 锁竞争 | 既有 4 项想看、6 项反馈及 6 项反馈边界并发回归通过 |
| 同游标并发读 | 新增 4 个真实 PostgreSQL 连接同时读取，位置/结果相同，无业务写入 |
| 回退 | 开关关闭、发布代次变化、重新开启、缓存故障及命名空间隔离 |
| 诊断工具自身安全 | 明确授权才能读、仅精确指定账号、READ ONLY、无长评查询、匿名报告 |

## 真实线上只读基线

两个已授权自然账号各 25 次有界请求、53 项断言通过。仅正常登录使用 POST；业务全部 GET。验证了均衡与旧列表相等、分页/换批/证据一致、非法参数拒绝、画像/偏好/反馈摘要前后不变。

线上能力接口仍返回 404，报告明确为 `passed_pre9c_baseline_only`，**不是 9C 部署通过**。两份报告均未包含密码、JWT、游标或来源作品个人评分。没有线上切换开关、隐藏、撤销、加入或修改偏好。

真实账号首屏 HTTP 与本机 SQL 抽查见 [性能记录](recommendations-9c-performance.md)。线上首屏延迟仍为待验收事项，不放宽 V2 门槛，也不把单次抽查当作负载测试。

1. 待部署 9C 前后端，再执行不带 `--allow-pre9c` 的只读脚本及真实页面桌面/窄屏复验。
2. 待记录部署端冷/热首屏、worker 内公共缓存命中、SQL 与计算耗时。当前 HTTP 客户端不能读取服务器内部指标，报告中保持 null，而非猜测为 0。
3. 公共缓存为 worker 本地短缓存，进程重启/多 worker 会各自冷启动；生产收益未获证实。可独立关闭缓存而不关闭增强 9。
4. 发布代次必须由运维在所有 worker 同步更新；旧 9B 前端需刷新到 9C 才能自动回退。不能对旧静态包承诺无缝回退。
5. 本轮没有真实生产写入/压力测试，也没有自动改变部署配置。

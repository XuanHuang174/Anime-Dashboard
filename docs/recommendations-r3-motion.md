# R3：推荐页动效与转场

## 呈现与边界

- 页眉轻入场：10px、0.32 秒。
- 主推作品与口味便签：最多 16px、0.36 秒；不等待海报下载，不延迟按钮或推荐请求。
- 网格卡片：进入视口后播放一次；追加只处理新 DOM 身份。卡片间错开最多累计 0.12 秒，不让一整批逐张排队。
- 换批/分类/筛选：旧数据按原状态机立即作废，新结果到达后入场。不保留旧证据做退场，不改变原有滚动和结果区焦点策略。
- 原生 Dialog：`showModal()` 和初始焦点立即生效，之后进行 0.22 秒轻量入场；关闭、取消请求、证据失效与焦点恢复不等待动画。
- 证据展开：正文最多移动 4px、0.18 秒；不动画高度，不延迟真实内容，不发起新的推荐请求。
- 精细指针悬停：海报轻微放大 1.025 倍；沿用按钮硬阴影按压反馈，不为每次悬停创建 GSAP 实例。
- 资源面板继续使用已有 Dialog 内部转场，不另做一套资源抽屉；不开启 V2，不改变 V1 排序、用户数据或写入服务。

## 工程约束

复用项目已有 GSAP 3.15，不增加依赖、远程素材或外部字体。动效服务与 React hook 独立于业务控制器；动画完成回调不调用接口、不更新业务状态。

默认 CSS 始终可见，不预设透明度 0。没有 IntersectionObserver 时立即处理卡片入场，不留下隐藏内容；动画只改变 transform、opacity 和临时 will-change。每段动画由本地 `gsap.context` 管理，完成后恢复原样式。

清理范围严格限定于本页面/弹窗：不调用全局时间线清空、全局 killTweensOf 或全局 clearProps。新上下文、卸载和减少动态效果变化会取消对应动画与观察器；代次及 DOM 身份校验拦截迟到回调。同一节点复用时先取消旧动画，避免其完成回调恢复到新的动画上。

`prefers-reduced-motion: reduce` 在首次进入和运行中切换均生效：立即停止 GSAP，资源/按钮等 CSS 转场关闭；重新开启动态效果不重播当前卡片、不重新获取推荐。仅后续新内容可入场。

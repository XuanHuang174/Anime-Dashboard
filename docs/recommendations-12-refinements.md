# 扩展 12：提醒刷新与展示优化

日期：2026-10-26。本轮为用户确认普通账号登录态可正常使用扩展 12 后的体验优化。普通账号结果来自用户实际页面验收，没有新增代理登录报告或 Render Shell 审计。

## 展示行为

- 后续提醒：没有保存过设置的账号默认收起；已有明确展开/收起偏好继续生效。首次收起只读展示设置，不计算提醒列表，不展示未经读取的数量。展开后才读取内容，收起后保留简要标题、已知数量和展开按钮。
- 单番相似的直接关联：默认收起，保留当前条件下的数量。展开/收起不发起请求，不改变相似结果中排除直接关联的规则。同一参照作品的筛选、分页及当前会话内模块往返保留展开选择；切换参照或内容范围恢复收起。
- 私人手账预览详情的“系列与关联”加入现有 `memphis-modal-piece` 分段 GSAP 入场，并沿用减少动态效果分支。
- 系列页主标题和关联作品标题采用白字黑底。共享筛选器统一使用“6.0 以下（不含未知评分）”。

## 提醒读取与失效

提醒控制器由推荐主容器持有，仅在当前账号及内容范围的 React 内存中存活。三模块往返复用数据；刷新网页、切换账号或内容范围会重新建立控制器。私人列表、上下文和令牌不写入 localStorage；跨标签页仅传递不含作品或账号信息的失效通知。

首次进入读取新增的 `GET /api/recommendations/series/reminders/presentation/`，仅包含展示设置、隐藏集合摘要、公共系列修订和原有内容范围合同，不解析手账、不建立关系图。折叠状态通过同路径 PATCH 保存，使用 `expected_version` 检查并发，不重新计算列表；旧版完整提醒 PATCH 继续兼容。

完整列表按原 15 分钟上下文与内容范围期限失效。短时切换前后台不会重复读完整列表；个人推荐可见时每 30 秒最多读取一次轻量设置/修订元数据，离开该模块或后台时不自动重算完整列表。公共系列或隐藏摘要变化才使现有内容失效，单纯展示版本变化只更新折叠状态与写入版本。完整读取合并并发请求；读取期间发生变更时丢弃旧响应，再读取当前结果。

本人记录的新增/删除、观看状态和作品身份变化，以及隐藏/恢复反馈会触发失效，合并 250 毫秒内连续通知。仅评分、评价、私人标签或观看集数变化不改变提醒依据，不重算提醒。展开时更新；收起时等到再次展开。正常刷新保留现有展示；授权或内容范围失效时清除旧数据。保存结果不明确时提示重读，不自动重放写入。

## 部署

后端与前端均需正常部署，无新增环境变量。沿用部署迁移命令应用 `0015_alter_seriesreminderstate_collapsed`：只将模型默认值设为 True，不批量更新已有设置。

```bash
python manage.py migrate
```

本轮未修改生产数据库、Render 环境变量或既有全量放行设置。

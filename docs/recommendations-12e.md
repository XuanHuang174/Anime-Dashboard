# 扩展 12E：手账续作提醒

日期：2026-10-25。按 [扩展 12 方案](recommendations-extension-12-plan.md) 交付。保持个性化推荐、单番相似、按标签找三个导航；没有新增本季榜、通知推送或后台定时任务。本轮仅在本机合成环境验收，没有修改 Render、生产数据或线上开关。

## 用户看到什么

个性化推荐页的筛选栏之后、首推之前，增加“你看过的故事，还有后续”轻量区块。桌面双列、手机单列，每次最多 6 部。每条说明依据哪部本人已记录看完的作品，分别显示发行日期、发行形式和“无已确认记录”。日期不代表已经播出、可观看或建议观看顺序。

“查看后续与关系”进入原系列页并打开对应作品详情，沿用既有加入想看、资源检索与身份核对闭环。反向来源的后续可能就是系列页本作，因此系列页补充“查看本作详情”。若关联超过原系列页 200 条展示边界，则保留关系页，不自动打开页外条目。返回保留原推荐批次、筛选及位置；已加入想看的作品会在重新读取后退出提醒。

支持“收起后续提醒”“隐藏这条提醒”“恢复隐藏的后续提醒”。这些设置保存在账号下，重新进入仍生效；恢复操作恢复本人在此区块隐藏的所有作品，当前范围的计数不暴露其他范围的标题或数量。跨标签页只发送无内容的失效标记，接收方重新鉴权并读取自己的设置。没有符合条件的作品、没有隐藏项且未收起时，不占据推荐页面空间。

提醒不受主推荐的年份、类型、评分筛选影响，标题旁明确写出自己的依据；内容范围始终与本次浏览同步。它不会重排个性化推荐或移除原候选。

## 提醒规则

- 来源必须是本人身份已确认、当前内容范围可见、状态为已看完的记录。严格复用既有 Bangumi ID 与有效别名解析，不按标题猜测。
- 使用 12D 已复核的当前直接事实，仅接受 A→B“续集”或 B→A“前传”所表达的 B 是 A 的后续。保留原方向与原来源，不虚构新断言。
- 总集篇、全集、番外、衍生、改编、同世界观、角色出演等不当作后续；不从 A→B→C 推断 A→C。互相矛盾的前后关系跳过。
- 来源观察超过 45 天则不用于主动提醒。近期有效的上次观察可以继续使用；新一轮获取失败不会编造新关系。关系页仍显示完整的覆盖情况。
- 目标只允许已收录、分级与节点一致且当前范围可见的动画。NSFW 必须仍有有效审核及服务资格；未知分级、未审核及未收录条目不返回标题或计数。
- 目标存在本人任意观看状态的记录就退出提醒；旧别名过期、冲突或待核对时，也保守排除对应的直接/别名 ID。无已确认记录不写成“没看过”。
- 现有“不感兴趣”反馈对来源及目标都生效。此区块自己的隐藏记录独立保存，不修改原推荐反馈或长期题材偏好。
- 一个目标合并多个已看完来源；同一来源的互为前后断言只算一个依据。按发行日期及 ID 稳定展示，未知日期排后。6 条只是展示上限，不限制实际排除与隐藏计数。

读取最多 5000 条本人记录及 12D 的有界直接图，超限明确不可用，不用部分资料伪造完整提醒。全部 GET 使用只读一致快照，不创建设置或写入身份；不读取个人评分、长评及私人标签。

## 接口与状态

`GET /api/recommendations/series/reminders/` 返回 `recommendations.series.reminders.v1`，独立策略为 `series-reminders.completed-direct.v1`。结果包含当前展示、收起状态、设置版本及签名上下文，不接受指定其他用户的参数。响应为 private/no-store。

同地址 `PATCH` 使用严格的小 JSON 合同：

```json
{"action":"hide","bangumi_id":2,"expected_version":0,"context":"GET 返回的签名上下文"}
```

另外两种操作分别为 `action=collapse` 加布尔 `collapsed`，以及无额外字段的 `action=restore`。上下文绑定本人、内容范围及当前依据，有效期 900 秒；写入串行锁定账号，校验版本和当前依据。关系、目录、本人已看完/已有记录、反馈或设置变化后，旧操作返回 `series_snapshot_changed`，不能当作 NSFW 授权丢失。

发送 GET 前重新验证当前依据。前端定期、前台恢复、记录变更及关系页返回时重读；到期先撤下旧操作。请求取消、账号/范围变化及迟到响应都有隔离。写入不乐观隐藏，收到确认后再读取服务端结果；网络不确定时不自动重放 PATCH，提示重新读取实际状态。已确认保存但刷新失败会明确区分。

新增迁移 `0014_series_reminders`，仅增加两张私人展示设置表：账号级收起/版本及账号+Bangumi ID 的隐藏状态。没有改动手账、推荐偏好或公共关系表；恢复隐藏通过更新状态完成，没有删除记录。

## 启用与回退

部署须先执行正常迁移，再在 12F 验收范围内启用：

```text
RECOMMENDATION_EXPLORATION_ENABLED=True
RECOMMENDATION_SERIES_ENABLED=True
RECOMMENDATION_SERIES_EXPLORATION_ENABLED=True
RECOMMENDATION_SERIES_REMINDERS_ENABLED=True
```

新提醒开关默认 False，沿用探索灰度账号名单。所有依赖开启且账号在范围内，能力描述才增加 `series_reminders`；关闭时保持旧合同。关闭新开关并刷新页面即可移除区块，原推荐及详情继续可用，已保存设置保留。关系服务失败只影响本区，不阻断原推荐页。

## 工程边界与验证

- 不修改 V1 默认引擎、排序公式、浏览风格或前端布局，不启用 V2。新题材会合理改变特征、画像、关联候选及证据，不声称所有用户的结果完全不变。
- 特征提取仅作用于副本，不改写公共/私人标签、个人评分（包含真实 0 分）、长评、观看状态或作品身份。私人标签主动清空时仍不回补目录标签。
- 旧 v7 词表、别名、定义冻结，历史离线审计不会被新规则污染。
- `genres.v8` 自动进入特征/选项缓存命名空间及画像、分页、证据上下文；旧游标和证据令牌返回 409，按现有页面流程重新读取。
- 新增隔离 PostgreSQL 测试覆盖精确十项、零新增别名、51 项 API、20 项上限、偏好版本冲突、公共频次排序、数据逐字段保护、多用户隔离、安全过滤、旧缓存/游标/证据失效及旧规范特征数据的 V1 同条件排序一致性。
- 新增前端合同测试验证 51 项真实接口选项渲染、服务端顺序、默认不勾选、不推断父题材、草稿保存及选择上限。

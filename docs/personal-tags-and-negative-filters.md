# 常用标签与负向快速筛选

## 使用方式

- 编辑作品 → 快捷预设 → 管理常用：输入标签或选择手账已有标签后保存。我的常用在默认预设上方，点击即可添加到当前作品。也可在左侧增加自定义标签时勾选“同时保存为常用标签”。
- 常用标签按账号保存在后端，最多 64 个、每个最多 50 字。移除常用入口不会修改作品标签。保存常用与保存作品是两个独立操作，取消作品编辑仍会保留已经保存的常用项。
- 快速筛选编辑器支持包含标签／标题词、排除标签／标题词，可只设置排除条件。排除命中任意一项即剔除，包含条件再根据“任意／全部”匹配。标签精确匹配，标题词匹配中日文标题且英文不区分大小写。
- 包含与排除不能冲突；标签各最多 8 个，标题词各最多 4 个、每词最多 30 字。现有组合保留；编辑时保留既有标题关键词。选中组合后筛选栏显示条件摘要。
- OVA、剧场版等仍按标签／标题词识别，不承诺没有标签或关键词的作品会按类型自动排除。全部模式由前端筛选；分页模式在后端筛选后分页，两者语义一致。

## Bangumi 收藏导入

原有收藏导入代码没有主动添加书名号。本次补上来源名称外层成对《》的去除，保留名称内部符号；不批量改写已有手账名称。智能录入此前的外层书名号处理继续生效。

## 部署

新增迁移 `anime/0024_featuredquickfilter_exclude_tags_and_more.py`，应先随后端部署执行 `python manage.py migrate --noinput`，再更新前端。无新增环境变量。新增账号专用 `/api/tag-presets/`，GET 读取、POST `{tag}` 添加、DELETE `{tag}` 移除；服务端从当前登录身份确定归属，使用账号锁串行合并，不接收用户 ID。

快速筛选共用序列化器，因此用户组合与管理员维护的公共筛选模型均新增空的排除字段，旧数据的排除条件默认空。私人常用标签不进入公共资料序列化器。

本地隔离测试覆盖账号隔离、去重、边界、筛选冲突、分页前排除、中日文标题匹配和收藏导入名称；生产迁移与用户数据未在开发验证中修改。

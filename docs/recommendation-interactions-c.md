# 批次 C：推荐详情与返回体验

## 本轮界面修正

- 快速筛选的名称、匹配方式与下方条件放入同一滚动网格，统一两列宽度、列间距及滚动条占位，避免上下右边界错位。手机窄屏统一单列。
- 推荐三模式恢复紧凑导航和浅底黑边说明框。针对共享布局 CSS 较晚加载覆盖主题的问题，提高导航区域主题规则的针对性；偏好设置按最后确认保留在筛选旁。
- “偏好设置”移动到筛选旁源于较早的 `85d10c7` 工具栏调整，并非本次 A/B 修改。

## 卡片及详情

- 个性化、单番相似、标签探索的主推和普通卡片，以及人物/制作的参与作品卡片，都支持海报、标题和非交互空白区进入详情。海报、标题采用原生按钮，支持键盘与焦点提示。
- 想看、隐藏菜单、标签跳转、证据/角色展开等交互保留各自行为，不冒泡打开详情；选中文字时不进入详情。失效/不可用列表继续禁用进入详情。
- 详情的关闭、想看、资源、找相似操作放入独立底栏，与正文滚动区域分离；短屏底栏可换行并在必要时自身滚动。人物作品详情同步固定想看、资源操作。
- 推荐、相似、题材依据默认折叠，用户仍可展开。资源面板继续使用原有桌面并排/手机覆盖布局、焦点管理及 Escape 逐层返回。
- 写入确认、失败重试、过期依据、内容范围和身份判断沿用原实现，没有新增业务写接口。

## 返回快照

原先每个模块只有一个缓存槽，更换相似参照或标签查询会覆盖前一个浏览状态。
现改为按模式、完整查询路径、内容范围保留最多 12 个最近视图，包含原控制器及其
已加载分页、筛选、参照、草稿和滚动位置。导航入口返回各模式最近一次查询，
浏览器返回也可恢复更早的参照/标签组合。

滚动位置在原页面仍显示时记录，避免卸载时读到短目标页面已压缩后的 scrollY。
快照仅由当前账号键下的 React 主机持有，不进入 localStorage/sessionStorage 或全局单例；
刷新、退出探索主机或切换账号后释放，超出上限按最近访问顺序淘汰。
返回仍调用既有上下文校验，失效后保留列表位置、移除旧依据并要求明确重新读取；
快照不会绕过内容授权或自动重放写入。人物/系列覆盖页继续使用原有保留底层页面的路由机制。

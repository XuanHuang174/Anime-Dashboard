# 手账体验修复与标准作品关联管理

本轮接在 B3 后完成体验修复。C（月度／自选时间段回顾，再扩展年度）尚未开始。

## 用户入口与行为

- 从预览直接前往观看历程、观看安排或核对标准作品时，统一进入编辑模式并刷新记录。列表末行、海报墙末卡的“添加番剧”占位会正常显示与响应。
- 滚动入场只对实际观察中的元素设置待入场透明状态；新增节点会补充观察。没有观察器、减少动态效果或组件切换时，内容仍可见，并清理观察器、动画帧与计时器。
- 独立观看安排保留标题中的“独立保存”，去掉底部重复且偏位的提示，返回和关闭位于两侧。
- 手账画布至少覆盖动态视口，装饰在独立裁剪层中绘制。计划页不再使用隐藏手账的结果数量决定紧凑布局，零条、单条或多条筛选均不会露出页面底色。
- 添加计划抽屉支持点击面板外遮罩关闭；只有按下和点击均发生在面板外才关闭，面板内操作或从内部拖到外部不会误关。保留 Esc、关闭按钮、焦点恢复和背景滚动锁定。

“核对标准作品”增加“关联管理”：支持搜索已关联／已解除的本人记录，按名称、Bangumi 编号或条目 URL 查找新候选；详情中也有“管理标准作品关联”。原有待核对批量流程继续可用，草稿未处理时不能直接切换。

管理操作必须明确选择并勾选确认：更换、解除、撤销最近一次更正。不同季度有额外提示。解除会阻止自动回退到原始身份；更正只作用于当前用户的私人关联，不修改原始录入来源、公共 Anime、评分、长评、海报、历程或计划。系列、人物制作、标准链接、推荐画像和相关已收藏状态统一读取更正后的身份。公开手账继续按原有来源规则输出，不公开私人更正。

撤销只恢复最近一次更正前的状态，不连续回滚历史。记录、目录或内容权限变化时，服务端拒绝过期操作，用户重新搜索核对。恢复备份只恢复当前更正状态，不移植旧操作收据，也不提供跨备份的撤销链。

## 数据和部署

新增迁移 `recommendations/0017_recommendationidentityoverride_and_more.py`：

- `RecommendationIdentityOverride`：每条私人记录的覆盖／解除状态、单调版本与资料指纹。
- `RecommendationIdentityCorrection`：最小更正审计和 UUID 请求收据，用于原请求重试与最近一次撤销。

**部署时先运行正常环境的 `python manage.py migrate`，再重启后端及发布前端。** 本轮只迁移了隔离本地数据库，没有操作生产数据库。

`GET /api/recommendations/identities/manage/` 返回本人管理列表或指定记录及候选；`POST` 接受 `replace`／`unlink`／`undo`。写入顺序为账号锁、私人记录、内容范围、覆盖记录与目录，校验账号签名、十五分钟凭据、旧版本、资料指纹和当前内容权限。更正和操作收据在同一事务中落库。相同 UUID／请求重试只读取回执，不重新应用；不同请求复用 UUID 拒绝。前端在回执未知时保留原 UUID 和请求体；409 后要求刷新并重新选择。

JSON 导出增加可空的 `anime.identity_correction`（目标编号及账号绑定签名）。恢复验证账号与作品资料；无效更正让整次恢复回滚，不能悄悄丢弃后自动匹配。旧备份缺少此字段时按唯一的中日名和季度保留现有更正，无法唯一识别则拒绝。失效关联在备份恢复后继续保持待核对，不会借恢复重新确认。原有 `identity_reference` 兼容保留。签名使用现有服务密钥；跨账号恢复私人更正须先在目标账号明确重新核对。

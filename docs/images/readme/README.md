# README 配图指南

根目录 [README.md](../../../README.md) 预留了 7 个截图位置，目前统一使用 `placeholder.svg`，不会产生断图，也不会将合成验收图当成真实界面。

## 如何补图

1. 把截图放进当前目录 `docs/images/readme/`，按下表命名。
2. 在根 README 中找到对应注释，将它下面或旁边的图片 `src`／Markdown 图片路径改为实际路径。
3. PNG、JPEG、WebP 都可以；如不使用 WebP，请同时更改 README 中的扩展名。
4. 图已经存在后再替换引用。全部补好后，可以按需删去 README 的“截图预留位置”提示与总览图下的配图提示。

例如，将：

```html
<img src="docs/images/readme/placeholder.svg" width="460" alt="私人手账截图待补充" />
```

改为：

```html
<img src="docs/images/readme/02-journal.webp" width="460" alt="私人手账：个人评分、观看进度与标签整理" />
```

## 截图清单

| 文件名 | 推荐内容 | 构图建议 |
| --- | --- | --- |
| `01-overview.webp` | 公共主界面全景，或手账与探索的拼图 | 作为首屏主图，约 1600 × 900；保留页面标题与代表性卡片 |
| `02-journal.webp` | 私人手账预览，包含统计、筛选和作品列表 | 约 1600 × 900；使用自己愿意展示的资料 |
| `03-discovery.webp` | 个性化推荐首屏，含四个探索入口、首推和口味区 | 约 1600 × 900；不用截整张超长列表 |
| `04-series.webp` | 系列页，展示故事前后与至少一类其他关系 | 约 1600 × 900；折叠说明，让作品关系成为主体 |
| `05-credits.webp` | 某位声优或制作公司的参与作品页 | 约 1600 × 900；包含实体名称、筛选入口和作品卡片 |
| `06-community.webp` | 精选专栏或共创大厅 | 约 1600 × 900；选有代表性的公开内容 |
| `07-completion-report.webp` | 实际导出的结案报告图片 | 优先放原始导出图，可在浅色底上排成横向展示图，避免拉伸 |

可额外补充手机端菜单、筛选抽屉和作品详情截图，放在对应功能段落下即可。

## 展示建议

- 先补总览、手账、探索三张，仓库首页的观感提升最明显。
- 尽量统一桌面截图比例、缩放与窗口宽度；在 GitHub 半宽展示时仍应能辨认主标题。
- 建议单图压缩到 1 MB 左右或更小，保持文字清晰；不必为凑比例截入大量空白。
- 遮挡邮箱、账号私密信息、管理凭据和不希望公开的长评；截图内容应适合仓库公开展示。
- 使用真实页面或自己的示例账号，不将带“合成验收”字样的本机测试画面作为线上成果。
- 上传后检查 GitHub 桌面与手机上的排版。保留当前 SVG 占位图也可以，无需为了清理素材批量删除文件。

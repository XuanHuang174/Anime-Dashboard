# 推荐页：宽版偏好工作台

## 范围

复用原生 `RecommendationDialog`、三区块 `RecommendationPreferencesPanel`、`createPreferenceEditor` 和现有 API。仅改变布局、文案密度与焦点归位，不修改数据库、推荐算法、版本开关或用户资料；线上仍走现有 V1。无新依赖，无第二套弹窗。

## 布局和交互

- 桌面（视口宽度 ≥ 1100px）：居中宽版卡片，最大 1320px，高度随视口限制。白色明确偏好 / 青绿只读画像 / 淡黄待确认题材三列，比例 1.2:1:1。
- 每列标题固定，内容独立滚动，支持键盘聚焦和原生滚动。保留细滚动条与可见焦点，不隐藏内容、不自动折叠题材。
- 平板、窄屏（< 1100px）：三块纵向排列，共用一个内容滚动区，避免触屏嵌套滚动。手机为底部面板，适配安全区和矮横屏。
- 说明区与操作区不随列内容滚走。底部左侧显示草稿数量，右下角取消与保存；手机双按钮并排。
- 错误、保存确认不确定及冲突处理位于独立的底部消息区。消息过长可滚动，但不挤走保存/取消。
- 保留现有 GSAP 原生弹窗入场与减少动效设置，不新增循环动画。
- 关闭会只读刷新资料；因读取而短暂禁用的原入口，在读取结束后归还焦点。用户已主动转移焦点时不抢焦点；便签入口在重载中被替换时回到顶部偏好入口。

## 保留的数据合同

选择、观察题材加入和清空只改变本地草稿；关闭不写入。最多 20 项，仅统一保存触发 PATCH。

现有保存连击合并、版本校验、冲突读取/合并、失败保留草稿、保存成功但推荐刷新失败的只读重试均保持。只读画像不能勾选，观察题材最多 8 项且默认不保存。清空手动选择不删除画像或手账。

所有新增样式在 `.memphis-rec-container` 内，弹窗尺寸仅匹配 `rec-dialog--preferences`，不改变筛选、详情、资源或隐藏作品抽屉。

## 验证

仅本地合成数据，不连接 Neon、R2、资源服务或真实账号；模拟 PATCH 不写任何数据库。生产接口与线上页面尚待部署后验收。

## 部署与回退

仅前端构建与部署，无迁移和后台任务。上线后可先只读检查三列、手机滚动、取消草稿、Escape 及焦点归位；真实偏好保存应使用授权测试账号，勿改写其他用户数据。

需要回退时正常 revert 本次提交并重新构建部署，无需切换 V2、清理用户偏好/反馈或数据库；不要批量删除文件。

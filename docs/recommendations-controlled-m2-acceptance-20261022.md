| 成人封面 | 强制中性占位；服务端空封面与前端二次屏蔽均覆盖 |
| 私人样本 | 已授权成人作品也不能成为高分画像来源；私人长评不进入诊断或证据 |
| 加入想看 | 重复请求只用已有记录；私人字段逐字段保留，个人 0 分不丢失，新成人资料非公开 |
| 反馈与撤销 | 用户隔离、范围一致、清单按授权可见；不修改手账 |
| 批次／证据失效 | 换范围、关闸、撤销、审核／目录变化使旧游标和依据失效 |
| 到期 | 不依赖写入计数；审核自然到期失效，游标期限不晚于最早授权／审核期限 |
| 返回前复核 | 只读事务关闭后候选被改为未知分级，最终响应拒绝而不是发送旧结果 |
| 总开关并发 | 两个竞争操作只允许一个预期版本胜出，另一个 409；审计失败整体回滚 |
| 关闸与加入竞争 | 等待控制锁的加入在关闸提交后 409，无新增手账 |
| 并发成人加入和反馈 | 两次加入仅新增一条记录；反馈同时发生不覆盖私人字段 |

| 管理端 | 普通用户／非超级管理员拒绝；15 分钟签名绑定操作者、目标账号、版本和操作编号 |
| 不确定提交 | 同编号／同凭据重试；版本冲突要求重读，不覆盖新决定 |
| 前端异步隔离 | 范围随所有相关请求发送；撤销／范围变化退出旧会话；已取消旧错误不重置新会话 |

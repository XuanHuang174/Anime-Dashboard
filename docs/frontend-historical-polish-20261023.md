# 手账背景、返回顶部与推荐入场优化（2026-10-23）

后续调整：顶部 16px 间隔现仅适用于编辑模式，预览模式已恢复红色页头贴顶；同时优化了作品修改面板的滚动布局，见[预览贴顶与作品编辑布局调整](edit-record-layout-20261023.md)。下文保留本阶段实现与验收记录。

## 页面表现

- 编辑及预览模式的奶油色纹理背景覆盖页面顶部，页头保留 16px 内部间隔。移除编辑页头的 `mt-2`，在 `.memphis-dashboard` 内设置顶部 padding 和独立块格式化上下文，防止子元素外边距折叠到背景外。
- 推荐页继续使用共享 `BackToTop` 组件。共享样式增加颜色变量的默认值，解决推荐命名空间没有 `--memphis-*` 变量时背景、边框和阴影失效的问题；黄色方形、4px 黑边、6px 珊瑚色硬阴影及悬停按压效果与原界面一致。
- 推荐页入场改为区域顺序：顶部菜单功能 → 本批首推和我的口味 → 还有更多（标题与卡片网格整体）。顶部采用弹跳落入，内容采用与手账相近的位移、轻缩放及错开入场。

## 播放生命周期

播放状态只存在当前网页的模块内存中，不写入 localStorage/sessionStorage。SPA 路由返回、筛选、切分类、追加和换批不重复播放已经开始的模块；刷新或新开网页重新播放。

首推等待真实推荐数据就绪，再接续顶部动画。首次结果不足两部时，不消耗“还有更多”的播放机会，等该区域第一次出现再播放。加载失败、依据失效或组件卸载会撤销局部 GSAP 样式，避免遗留透明、隐藏或位移。React StrictMode 的探测挂载不会提前消耗尚未开始的动画。

系统开启“减少动态效果”时直接展示内容；中途开启时取消并清理当前动画，之后不补播。弹窗和“为什么推荐”展开动画保留各自的局部控制，不受页面首次播放状态影响。

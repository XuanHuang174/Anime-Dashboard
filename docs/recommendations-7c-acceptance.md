## 4. 本次修正

增加页面分类/筛选变化时的详情与资源主动清理，避免参数已经改变而旧弹窗仍保留。没有改变加入服务、推荐排序、用户记录写入语义或资源 API。

四项 PostgreSQL 竞争测试补上每个 worker 的真实 `pg_backend_pid()` 独立性断言，以及锁/SQL 超时，避免用共享连接串行运行冒充竞争；旧记录竞争样本改为显式个人 0 分、空私人基础标签和完整长评保护。

线上浏览器首轮脚本在资源响应到达、React 尚未完成渲染时过早判断，并将已拦截的第三方统计 POST 误计为业务写入，报告失败。改为等待局部 UI，并区分业务写入与被拦截统计请求后复验通过。保留原失败记录，不将测试脚本时序问题伪报成已部署产品缺陷。

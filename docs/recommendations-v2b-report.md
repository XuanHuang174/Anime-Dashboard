### 池规模与解释边界

首次运行的日常基线中，A发现/熟悉合格候选分别9966/9854，两版均入池400、返回120；A探索合格3044，新池275（原400）；B熟悉合格1026，新池200（原400）。这是固定75%相对相关性门槛的收缩，不是数据库缺记录，也不是增大候选上限的收益。

因此不能把候选减少造成的潜在耗时下降与“同规模性能优化”混为一谈；完整的V2-C性能优化尚未启动。探索类入池退步与该候选调度/门槛有关，未出现合格集合/基础分/证据变化；具体门槛和配额的贡献需要下一轮预先声明的消融，不凭这两个账号直接调参上线。

## 遗留问题与建议

1. 当前新召回没有通过“各类别覆盖不退步”的质量复核，探索方向仍需定向修正；不得仅为了满400或提高命中而取消关联门槛。
2. 历史与扩展集Top10仍为0，说明仅调整召回尚未证明前排收益；不能根据公共评分宣称喜欢概率，更不能以0命中直接证明整个算法无效。
3. 只有一个自然账号可做真实留出，少样本账号只提供冷启动/明确偏好回归；不具备全站泛化或统计显著性证据。
4. V2与增强9浏览控制/游标兼容、部署服务端性能、正式上线审批未在本阶段交付。

建议保留原V2召回作为对照，先对探索方向的保留门槛/候选配额做下一轮可追溯消融，再决定V2-C针对哪条路径优化；不自动上线当前候选，也不因本轮局部收益放宽验收。

# 观看计划 B2：工作区、详情安排与观看交互

## 入口与模式

接入 [B1 的数据与接口](watch-plans-b1.md)。私人手账标题区下新增“手账 / 观看计划”切换。两个视图分别保留当前页面内的筛选、分页和滚动位置，计划不继承手账外层搜索或已评分优先排序；重新打开页面默认回到手账。服务端保存的优先级和手动顺序跨设备一致。

编辑模式可以选择私人作品、编辑安排、移动顺序、开始/恢复/重看、移出和重新安排。预览模式只有查看、搜索、筛选、查看排序和打开详情；通过明确的“前往编辑管理计划 / 前往编辑安排”进入编辑。公开手账、精选快照及管理员公开手账审阅不显示私人工作区或安排卡片，也不请求私人计划接口。

工作区沿用青绿标题、浅黄选中、白色卡片、黑边及偏移阴影。优先级以旗标、文字和底色区分，不使用评分星级。手机为紧凑卡片，横屏与桌面逐步增加列；触控控件至少 44px，展开短过渡遵循减少动态效果。

## 工作区

- 阶段：当前计划（待开始+进行中）、待开始、进行中、已完成、已移出。计数范围明确为本人全部计划，不随当前筛选变化。
- 搜索中日文名称、筛选优先级，查看顺序支持手动、计划时间、最近加入；不把查看排序写回手动位置。列表使用服务端全量匹配与分页。
- 卡片展示海报、标题、优先级、目的和阶段、计划日期、短备注、当前状态及进度。详情可查看完整备注。
- 未设日期显示“时间未定”。年/月精度只有整个时间范围过去后才温和标注“可重新安排”，不生成逾期任务或改变状态。
- “选择手账作品”提供独立搜索和分页，打开该作品的编辑详情并展开观看安排；不会批量把想看收藏转为任务。
- 待开始提供开始/恢复/重看入口，进行中提供观看历程进度入口；已完成与已移出可重新安排。

## 详情中的观看安排

编辑详情在状态进度区下方加入默认收起的“观看安排”。展开才请求数据，计划修改单独保存。作品表单有未保存修改时，可查看但禁止计划写入，并明确提示先保存作品。

编辑安排时暂时停用作品输入、作品删除和整份作品保存，避免两套草稿相互覆盖。标题与底栏压缩为当前作品和独立保存提示，为手机表单留出空间。计划表单提供优先级、未定/年/月/日精度与最多 500 字备注；切换精度清空值，不自动补某一天。

关闭、收起、取消或切换安排操作时，已修改草稿可以继续或明确放弃。保存中阻止离开；未保存及待确认写入触发浏览器刷新提示。错误定位并获得焦点，键盘焦点留在编辑弹窗。安排结束后恢复原作品编辑页签与内容。

预览详情仅在有安排时显示简洁卡片，不为无计划作品保留空卡片。安排状态、日期和备注只读；入口明确切换到编辑模式。

## 实际观看与同步

队列中的开始按钮先打开当前作品的安排确认表单，并重新读取最新计划，**不直接开始**。首次/恢复会改为在看；重看说明保留旧轮、新轮从 0 集开始、综合评分和长评保持。实际开始日期默认未记录，绝不复制计划日期。

正在观看的作品通过既有观看历程记录进度、完成或撤销。完成和撤销仍按 B1 的轮次规则同步计划，不把普通状态改动误当成新一轮。实际开始确认有同步提交门闩，快速双击只产生一个请求。

POST `/api/records/<id>/watch-plan/` 在原响应上增加 `canonical_record`，由同一外层事务内的最新私人记录序列化产生；幂等重放也返回最新状态。前端校验作品身份、状态、进度与历程版本后同步详情、列表和统计，不把后续展示读取失败误报成实际写入失败。只改安排不会改作品本身或触发无关推荐刷新。

## 完整队列排序

排序仅在编辑模式、“当前计划”、手动顺序且搜索为空时开放。先选择优先级，再逐页读取该档**完整活跃队列**，所有页版本与总量必须相同、成员不重复；读取中变化则拒绝该草稿，要求重新读取。即使当前列表在第 2 页，也不会将当前页误当成完整队列。

桌面可拖动把手，所有尺寸均有带作品名称的上移/下移按钮。移动只影响本地草稿，明确保存后才发完整排列。存在修改时，取消、切换工作区、切换查看模式或返回主界面前确认是否放弃；不同档通过调整优先级处理。若发生版本冲突，保留排列供查看，取消并刷新后重新调整，不直接覆盖远端新顺序。

排序确认后必须重新读取展示，读取失败只提示刷新，不能再将已经成功的写入当作未确认操作。优先级和排序不会被备注修改、主手账评分排序或切换视图悄悄改写。

## 错误、账号与重试

计划控制器按当前账号隔离，取消过时读取，较晚发起的读取优先；账号变化忽略旧读写响应。已经读取或确认过的队列版本不允许被较旧响应回退。页面重新获得焦点时安全重读，保留填写；新版本下的元数据修改需明确核对换版。开始、移出和排序不得静默换版。

400/422/429 保留可修正表单，不自动重试。409 保留草稿并要求重新读取。连接失败、5xx 或不完整写入回执保留原路径、原请求、原 UUID，阻止另一条写入；即使主动读到了新状态，仍显示“重试原操作并核对结果”。重试沿用原编号，不能重复开始或把旧排列重放覆盖新顺序。用户可明确选择离开，提示稍后先核对结果。预览模式不提供写入重试按钮。

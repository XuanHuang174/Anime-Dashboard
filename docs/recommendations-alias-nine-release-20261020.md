## 身份、隐私与兼容性

- 映射只作用于推荐特征副本，目录原标签、私人基础标签、`custom_tags`、个人评分、观看状态、长评均不重写。
- 同一作品多个同义词归为一个特征；保留字段来源，不重复放大权重。
- 用户主动清空的私人标签不从公共目录补回；没有有效标签的记录不会被伪造为喜好样本。
- 原标签或映射目标等于作品名称时继续排除；不从名称、简介猜题材、身份、季度或续作。
- 成人和未知分级硬过滤不变；公共题材不充当安全评级。
- 手动明确偏好仍独立保存，API 只接受规范选项，不把“爱情”等别名写成新的手动偏好选项。
- `content.v1` 默认算法、IDF 公式、V1 排序公式、风格控制和限制均未修改。新识别特征会自然影响部分画像、语料权重、结果与证据，不能声称所有结果完全不变。只包含既有规范标签的同条件合成数据已验证排序、分数和理由相同。

## 版本失效与部署

无需数据库迁移，无需数据回填。服务部署新代码并重启后，下一次请求按新规则计算；本地验收及公共目录只读复验不代表线上服务已加载新版本。

现有公共特征缓存、浏览公共索引、分页快照以及详情证据均绑定 `taxonomy_version`。升级后新缓存与旧 `genres.v4` 缓存隔离，旧分页令牌、浏览游标和详情证据返回 409，由已有恢复入口重新读取第一页/详情，不能混入旧证据。

前后端滚动部署时无需改变预设列表；前端已有版本比较和 409 恢复逻辑。应完成所有后端实例的更新，避免新旧实例并存时反复要求重载。不使用 `FLUSHALL`、`cache.clear()` 或全站缓存删除；旧公共缓存自然过期。

部署后的只读检查：

1. 画像及推荐响应显示 `taxonomy_version=genres.v5`，推荐 `algorithm_version=content.v1`。
2. 偏好选项仍为 33 项、上限 20；萌系等未审核选项仍不可保存。
3. 列表与详情的证据版本一致；旧令牌返回 409 后可以重载。
4. 不通过线上写入或改评分来制造样本。使用合成测试库覆盖必要的写入与边界。

## 安全回退

如需回退，重新部署本发布前的已验证代码版本，保持 `RECOMMENDATION_ALGORITHM_VERSION=content.v1`、V2 浏览开关关闭。不要仅把版本字符串改回 `genres.v4` 而保留新增映射，否则会污染历史版本语义与缓存。

回退后 `genres.v5` 快照失效，前端重新读取；无需删除或恢复任何手账、偏好、反馈记录，也无需撤销数据库迁移。冻结的 `genres.v4` 词表仅用于离线比较，不是可由客户端指定的运行开关。

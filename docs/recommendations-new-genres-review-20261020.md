# 第二批 8 个新题材：技术审核与待确认结论

## 结论与授权边界

8 项均建议按以下定义进入精确特征白名单，等待用户最终确认后再实施。**本次是审核，不是启用：运行规则仍为 `genres.v5`，规范题材仍为 33 个，V1 默认引擎不变。** 不新增同义映射，不修改前端选项或运行代码，不改写任何公共/私人数据。

本批审核对象包含剧情题材、设定、叙事气质与审美特征，不应宣称全是互斥的剧情类型。现有词表已包含“治愈、热血”等气质特征，允许“萌系、动作、励志”等以明确偏好特征形式共存；不新增自动父级扩张、互斥分类或另一套排序维度。

审核配置见 `evaluation/tag-genres.20261020.review.json`。其 `status=pending_human_review`、`apply_to_production=false`；技术推荐不等于用户已批准发布。历史第一批 9 项映射不重复申请、不计入本轮收益。

## 审核依据与局限

复用现有 `audit_tag_expansion`，以第一批已启用后的 `genres.v5` 为基线，在 PostgreSQL 的 `REPEATABLE READ, READ ONLY` 事务内读取公共目录；当前安全目录为显式 `nsfw=False` 且有合法 Bangumi ID 的作品。

完整时间、目录与草案指纹、公共样例、逐标签统计见同名 JSON。目录指纹：

`5f476f5250292c8561cb1ed3da807828451410b66413ed872bfbaf7f8a75d1b5`

不读取私人手账、个人评分、长评、公共评分或简介，不访问外部模型。不通过标题、简介、封面猜题材、身份、系列或季度；名称只用于既有同名排除及人工展示。

这是标签准入与元数据审查，**不是逐部剧情核真或内容分级复审**。公共样例只证明目录中已有这个精确标签，不能据此证明每个公共标签都正确；不能根据熟悉的作品名称补贴缺失标签。样例按 Bangumi ID 固定顺序选取，不是随机或全量语义质量评测。

## 获批后的实施验收边界

1. 只新增这 8 个精确规范特征；其余未审词不启用、不自动映射。私人/公共标签原文不重写，清空私人标签不补回。
2. 同一作品同一特征只计一次；可共存的近邻特征不被盲目合并，不推断系列或续作。
3. 保持 V1 排序公式；新特征会自然影响画像、IDF 语料计数及结果，不能承诺所有顺序不变。暂不引入维度加权或 V2。
4. 规范选项从 33 到 41；用户手动选择上限继续为 20。前端继续通过偏好接口读取选项，不另存一套固定清单。
5. 新发布必须升级题材规则版本，冻结历史 `genres.v4` / `genres.v5` 供离线对照，验证旧缓存、分页游标与证据失效；无需新增业务表。
6. 在独立 PostgreSQL 合成数据中验证 8 项提取、反例、冷启动、同义去重、清空保护、用户隔离及安全过滤；对真实公共目录只读复验。没有用户最终确认前不执行上述开发。

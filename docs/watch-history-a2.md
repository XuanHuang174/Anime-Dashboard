# 观看历程 A2：详情入口、时间线与轮次交互

以下为 A2 交付记录。后续 [A3](watch-history-a3.md) 已将预览调整为只读、编辑调整为独立管理区，并完成清空、紧凑时间线及恢复确认；当前行为与发布要求以 A3 为准。

## 范围与入口

接入 [A1 数据与接口](watch-history-a1.md)，提供可操作的私人观看历程。入口均在作品详情内：

- 私人手账预览：点击“观看历程”展开，默认收起；未展开不请求历程。
- 私人手账编辑：底部“观看历程”打开同一详情工作区。若作品表单有未保存修改，按钮禁用并明确提示先保存；不丢弃作品草稿，也不把历程操作混入“保存全部修改”。
- 公开手账、精选快照均不呈现该入口，也不请求私人历程。

使用现有详情的滚动区域，不叠加新的弹窗。展开区以青绿标题、浅黄当前轮次、白色操作表单和竖向时间线组织，沿用黑边与偏移阴影。手机日期与进度表单改为单列，按钮保持至少 44px；展开和表单入场使用短过渡，遵循减少动态效果。

## 用户交互

- 显示当前轮次、当前状态/集数、已记录完成轮数和重看记录数。旧资料仅作为日期未知的初始状态，不推定用户过去实际重看过多少次。
- 根据当前状态提供开始、继续、记录进度、标记完成、搁置或开始重看；所有状态都可写随记、补录往事。
- 日期默认未记录，用户可选择只记得年份、年月或具体日期。切换精度清空日期值，不替用户补某一天。
- 重看表单明确说明保留上一轮、进度从 0 开始、综合评分和长评保持不变；最终按钮为“确认开始重看”。
- 下拉查看各轮次，可更正非作废轮次的日期、独立评分和备注；不会修改作品综合评分、当前进度或长评。已撤销轮次仍可查看。
- 补录往事要求大致或具体日期，只添加回忆，不重放成当前进度。
- 时间线按记录版本倒序、每页 10 条，分别显示实际日期、操作变化、随记、来源和系统记录时间。重看开始日期来自该次轮次快照；日期更正展示前后差异，不将系统时间称作观看日期。
- 最新可撤销操作先展示核对表单；重看撤销会将新轮作废、恢复旧轮。最近操作发生变化时，必须取消并重新选择，不能悄悄撤销另一条操作。

## 草稿与同步

切换操作、取消填写、收起历程、关闭详情或前往相似推荐时，未保存草稿可选择继续编辑或放弃。保存处理中阻止离开；未保存或结果待确认时，刷新/关闭页面使用浏览器标准提示。错误会进入视口并获得焦点，成功后焦点回到当前轮次摘要。

POST 成功响应在原历程契约上增加私有 `record`，为同一事务内的最新标准记录；重复提交确认也返回当前记录。前端通过 Dashboard 既有更新入口同步详情、列表、统计刷新和推荐变化通知，避免另一次读取失败后把已经成功的写入误报成失败。

版本冲突保留表单。用户主动重新读取后，旧表单仍绑定原版本；核对后点击“使用最新版本”才允许提交。撤销操作不支持这种直接换版，需要重新选择最近操作。

结果不明的连接/5xx/不完整响应保留原 UUID 和原始请求，不自动重放，也不允许创建另一条操作。主动“重试原操作并核对结果”沿用原编号；即使中间重新读取，待确认操作入口仍保留。若选择离开，则说明操作可能已保存，之后需先查看历程。400 校验或 429 拒绝不会被当作已提交成功。

账号切换或作品卸载取消请求，忽略迟到响应，不将旧账号内容写入新页面。未提交内容不持久化到公共存储。
